# 删除 API Key

最近更新时间：2025-09-28 18:50:42


## 操作说明

本文将为您介绍如何删除一个API Key。

## 操作步骤

**警告：**

删除后不可恢复，请谨慎操作！

1. 登录 [Agent 沙箱服务控制台](https://console.cloud.tencent.com/ags/sandbox?rid=1)，在左侧导航选择 **API Keys**。

2. 在 **API Keys** 列表页面，找到需要删除的 API Key，在**操作**列单击**删除**。

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/97302cfe804cf410f4f75071a92e2627.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/97302cfe804cf410f4f75071a92e2627.png)

3. 在**删除 ApiKey**窗口，确认并输入待删除的 API Key 名称，**确认无误后**，再单击**确定**。
