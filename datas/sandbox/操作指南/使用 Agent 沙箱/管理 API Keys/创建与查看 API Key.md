# 创建与查看 API Key

最近更新时间：2026-04-24 17:32:52


## 操作说明

本文将为您介绍如何创建一个新的 API Key 并保存，API Key 用于权限校验。

**警告：**

为降低密钥泄漏的风险，Agent 沙箱服务只在创建时提供 API Key， 后续不可再进行查询，请您务必妥善保存 API Key！

## 操作步骤

**注意：**

当前默认允许创建3个 API Keys，如果您有创建更多 API Keys 的需求，请 [提交工单](https://console.cloud.tencent.com/workorder/category) 联系我们。

1. 登录 [Agent 沙箱服务控制台](https://console.cloud.tencent.com/ags/sandbox?rid=1)。

2. 在左侧导航栏选择 **API Keys**。

3. 在 **API Keys**窗口，单击**新建**。

4. 在**创建 APIKEY**窗口输入 API Key 名称，单击**创建**。

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/11eb97045c282b954a1cdc3daf91213e.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/11eb97045c282b954a1cdc3daf91213e.png)

5. 保存 API key 并勾选**我已知晓并保存 API Key** 后，单击**确定**。
