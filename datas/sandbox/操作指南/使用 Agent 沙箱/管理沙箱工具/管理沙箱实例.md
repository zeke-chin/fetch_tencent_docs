# 管理沙箱实例

最近更新时间：2025-09-28 18:50:42


## 操作说明

本文将为您介绍如何在控制台中观测沙箱实例。

**说明：**

沙箱实例的创建只能通过 API、SDK 或 MCP 完成。

控制台仅提供观测能力。

## 操作步骤

1. 登录 [Agent 沙箱服务控制台](https://console.cloud.tencent.com/ags/sandbox?rid=1)，在左侧导航选择**沙箱工具**。

2. 在沙箱工具列表中，单击某个沙箱工具名称，进入工具详情页。

您可以在工具详情页的下方，看到当前工具下的沙箱实例列表。
