# 查看沙箱工具

最近更新时间：2025-09-28 18:50:42


## 操作场景

本文将为您介绍如何查看创建成功的沙箱工具，并查看沙箱工具详情。

## 操作步骤

1. 登录 [Agent 沙箱服务控制台](https://console.cloud.tencent.com/ags/sandbox?rid=1)，在左侧导航选择**沙箱工具**，可查看已创建的沙箱工具列表。

沙箱工具列表按照沙箱类型分为浏览器沙箱列表和代码解释器列表。

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/41fabdce502bd813e692ae241d69faf5.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/41fabdce502bd813e692ae241d69faf5.png)

2. 在沙箱工具列表中，单击具体的沙箱工具名称，即可进入沙箱工具详情页面。

![Image 4](https://qcloudimg.tencent-cloud.cn/image/document/f0cbdfd60622ba52d04d00d01aa0494a.png)
