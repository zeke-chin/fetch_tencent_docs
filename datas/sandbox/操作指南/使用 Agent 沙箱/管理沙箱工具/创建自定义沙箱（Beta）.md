# 创建自定义沙箱（Beta）

最近更新时间：2026-01-12 18:12:51


## 操作场景

本文将为您介绍如何创建一个新的自定义沙箱工具，并为后续启动沙箱实例做准备。

**注意：**

自定义沙箱工具当前仅支持广州地域，更多地域将陆续开放。

在 AgentRL 场景下，您可能会创建大规模自定义镜像，为降低创建大量自定义沙箱工具带来的运维成本，AGS 支持在启动沙箱实例时重置沙箱工具镜像，提升大规模场景的易用性。

## 操作步骤

1. 登录 [Agent 沙箱服务控制台](https://console.cloud.tencent.com/ags/sandbox?rid=1)，在左侧导航选择**沙箱工具**。

2. 选择**自定义沙箱（Beta）**，单击**新建沙箱工具**。如下图所示：

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/198b94aaeb84a9d172fdc37a965c87e4.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/198b94aaeb84a9d172fdc37a965c87e4.png)

3. 在**新建沙箱工具**窗口，填写具体参数信息并单击**确定**。

参数类型 参数名称 是否必填 参数说明
基本信息 工具名称 必填 指定创建的沙箱工具名称。

名称命名规则：最长60个字符，只能包含字母、数字及分隔符("-")，且必须以字母开头。
描述 非必填 自定义沙箱工具的描述。

最长255个字符。
生命周期 必填 单个沙箱实例在创建后可存续的最长时间，超时将自动销毁。避免长期占用资源。

默认值：5m。

最长24小时。

支持格式参考：5m、300s、1h。
腾讯云标签 非必填 标签用于从不同维度对资源分类管理。如现有标签不符合您的要求，您亦可前往 [标签控制台](https://console.cloud.tencent.com/tag/taglist) 统一管理标签。
权限配置 权限配置 非必填 为您的沙箱工具配置云资源（例如 COS、镜像仓库）的访问权限。
自定义配置 镜像 必填 镜像来源支持**容器镜像服务企业版**和**个人版**。
镜像版本 非必填 镜像 Tag，不填默认为 `latest`。
启动命令 非必填 控制容器运行的输入命令。
启动参数 非必填 传递给容器运行命令的输入参数。
环境变量 非必填 只能包含字母、数字及分隔符("-"、"_"、".")；变量名为空时，在变量名称中粘贴一行或多行 key=value 或 key: value 的键值对可以实现快速批量输入。
自定义端口 非必填 自定义监听端口。
资源规格 必填 支持 CPU 和内存比为1:1；1:2；1:4配置，如有其他配置，可 [提交工单](https://console.cloud.tencent.com/workorder/category) 处理。
健康检查 必填 用于探测沙箱中运行的自定义镜像是否正常运行。
网络配置 网络配置 必填 沙箱支持三种类型的网络策略：

**沙箱内网**：沙箱禁止访问公网服务或者 VPC 网络，适用于需高度安全隔离的场景。**默认选项**。

**公网**：允许沙箱访问公网服务，适用于需要联网调用第三方 API、下载依赖等场景。

**说明：**

自定义镜像支持 **VPC 网络**即将上线。
文件系统 存储配置 非必填 自定义镜像支持以下持久化存储方式：

**镜像**：将镜像中的文件系统内容以 Volume 的形式挂载到沙箱实例中，在沙箱实例启动时直接复用镜像内的预置数据与依赖。

**说明：**

自定义镜像支持 **COSFS** 即将上线，届时支持：

在沙箱工具维度统一挂载同一 COS 路径，确保工具下所有沙箱实例共享数据。

按沙箱实例进行路径隔离，满足多实例并发运行下的数据安全与独立性需求。

4. 创建完成后，您可在沙箱详情页面查看，以便后续在启动沙箱实例时使用。
