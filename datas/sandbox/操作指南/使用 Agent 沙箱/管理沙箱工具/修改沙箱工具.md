# 修改沙箱工具

最近更新时间：2025-09-28 18:50:42


## 操作场景

本文将为您介绍如何修改一个沙箱工具的描述及标签信息。

## 操作步骤

1. 登录 [Agent 沙箱服务控制台](https://console.cloud.tencent.com/ags/sandbox?rid=1)，在左侧导航选择**沙箱工具。**

2. 在目标沙箱工具的**操作**列单击**编辑**。

**说明：**

目前沙箱工具修改只支持修改描述和腾讯云标签。

3. 在**更新沙箱工具**窗口，填写新的描述或选择新的标签后，单击**更新**。
