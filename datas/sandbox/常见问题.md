# 常见问题

最近更新时间：2026-04-24 17:32:52


## 如何使用 Agent Sandbox ？

用户既可以通过控制台创建 API Key 和沙箱工具，在客户端安装 SDK、配置环境变量后直接启动沙箱；同时，它兼容 E2B 使用方式，只需替换域名和密钥即可丝滑迁移现有业务代码，帮助开发者快速接入并安全高效地运行 Agent 任务。

## Agent 沙箱服务和 Agent 运行时的区别是什么？

Agent 沙箱服务：强调的是基础设施层，提供隔离、安全、可控的任务运行环境，相当于为 Agent 配置一个独立、可信的“工作环境”。它解决的是环境安全、弹性供给和执行隔离的问题，让 Agent 可以放心地运行任务。

Agent 运行时：更偏向于托管与执行层，是为 Agent 提供完整的运行托管能力，主要提供 Agent 的部署、运维和管理能力。

## 桌面沙箱相关

### Agent Runtime 支持创建 Ubuntu 桌面沙箱吗？

支持**。**Agent Runtime 提供 [OSWorld 沙箱类型](https://github.com/xlang-ai/OSWorld)，预配置了完整的桌面 Ubuntu + GUI 环境，支持操作桌面软件，Agent 可通过屏幕截图 + 鼠标键盘操作与桌面环境交互。快速上手可参考官方 Cookbook 示例：[OSWorld for Ubuntu 示例](https://github.com/TencentCloudAgentRuntime/ags-cookbook/tree/main/examples/osworld-ags)。

如果预置的 OSWorld 镜像不满足需求，也可以使用**自定义工具**类型，基于自有镜像构建沙箱，预装业务所需的软件和工具。

### Agent Runtime 支持 Windows 桌面沙箱吗？

**即将支持。**Windows 桌面沙箱当前正在支持 WAA（Windows Agent Arena）。如需提前了解或参与测试，请 [提交工单](https://console.cloud.tencent.com/workorder/category) 联系我们。

### Agent Runtime 支持 macOS 桌面沙箱吗？

**暂不支持。**受底层虚拟化技术限制和 macOS 版权许可约束，目前没有 macOS 沙箱的支持计划。如有 macOS 环境需求，请 [提交工单](https://console.cloud.tencent.com/workorder/category) 联系我们。
