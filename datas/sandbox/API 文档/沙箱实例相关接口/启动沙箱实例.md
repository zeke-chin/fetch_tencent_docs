# 启动沙箱实例

最近更新时间：2026-04-27 01:08:06


## 1. 接口描述

接口请求域名： ags.tencentcloudapi.com 。

启动沙箱实例

默认接口请求频率限制：100次/秒。

 推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=ags&Version=2025-09-20&Action=StartSandboxInstance)

 API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](https://cloud.tencent.com/document/api/1814/124827)。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，本接口取值：StartSandboxInstance。 |
| Version | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，本接口取值：2025-09-20。 |
| Region | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，详见产品支持的 [地域列表](https://cloud.tencent.com/document/api/1814/124827#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| ToolId | 否 | String | 沙箱工具 ID，与 ToolName 至少有一个要填 示例值：sdt-ee4ywozw |
| ToolName | 否 | String | 沙箱工具名称，与 ToolId 至少有一个要填 示例值：my-browser-sandbox |
| Timeout | 否 | String | 超时时间，超过这个时间就自动回收实例。支持格式：5m、300s、1h 等，默认 5m。最小 30s，最大 24h 示例值：10m |
| ClientToken | 否 | String | 幂等性 Token，长度不超过 64 字符 示例值：instance-token-456 |
| MountOptions.N | 否 | Array of [MountOption](https://cloud.tencent.com/document/api/1814/124823#MountOption) | 沙箱实例存储挂载配置 |
| CustomConfiguration | 否 | [CustomConfiguration](https://cloud.tencent.com/document/api/1814/124823#CustomConfiguration) | 沙箱实例自定义配置 |
| AuthMode | 否 | String | 沙箱访问认证模式 枚举值： * DEFAULT： 默认，即 TOKEN 认证 * TOKEN： Token认证，即所有端口访问都需携带TOKEN * NONE： 免认证，即所有端口访问无需携带TOKEN * PUBLIC： 公开模式，即ENVD管理端口（49983）访问需携带TOKEN，其他端口无需携带TOKEN 默认值：DEFAULT 示例值：DEFAULT |
| Metadata.N | 否 | Array of [MetadataVar](https://cloud.tencent.com/document/api/1814/124823#MetadataVar) | 沙箱元数据 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| Instance | [SandboxInstance](https://cloud.tencent.com/document/api/1814/124823#SandboxInstance) | 创建的沙箱实例完整信息 |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 6. 错误码

以下仅列出了接口业务逻辑相关的错误码，其他错误码详见 [公共错误码](https://cloud.tencent.com/document/api/1814/124832#.E5.85.AC.E5.85.B1.E9.94.99.E8.AF.AF.E7.A0.81)。

| 错误码 | 描述 |
| --- | --- |
| AuthFailure | CAM签名/鉴权错误。 |
| AuthFailure.UnauthorizedOperation | 请求未CAM授权 |
| FailedOperation.DuplicateRequest | 重复请求（幂等性检查） |
| FailedOperation.RequestInProgress | 请求正在处理中（幂等性检查） |
| FailedOperation.StorageMount | 沙箱实例存储配置挂载失败 |
| InternalError | 内部错误。 |
| InvalidParameter | 参数错误。 |
| InvalidParameterValue.MountOption | MountOption部分参数填写错误 |
| InvalidParameterValue.StorageMount | StorageMount部分参数错误 |
| InvalidParameterValue.Timeout | 超时时间格式错误或超过最大限制 |
| LimitExceeded.SandboxInstance | 沙箱实例配额超限 |
| MissingParameter | 缺少参数错误。 |
| ResourceNotFound.SandboxTool | 沙箱工具不存在 |
| ResourceNotFound.StorageMount | 指定的StorageMount不存在 |
| ResourceUnavailable.SandboxTool | 沙箱工具不可用 |
