# 创建沙箱工具

最近更新时间：2026-07-01 01:09:04


## 1. 接口描述

接口请求域名： ags.tencentcloudapi.com 。

创建沙箱工具

默认接口请求频率限制：20次/秒。

 推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=ags&Version=2025-09-20&Action=CreateSandboxTool)

 API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](https://cloud.tencent.com/document/api/1814/124827)。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，本接口取值：CreateSandboxTool。 |
| Version | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，本接口取值：2025-09-20。 |
| Region | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，详见产品支持的 [地域列表](https://cloud.tencent.com/document/api/1814/124827#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| ToolName | 是 | String | 沙箱工具名称，长度 1-50 字符，支持英文、数字、下划线和连接线。同一 AppId 下沙箱工具名称必须唯一 示例值：code-interpreter-v1 |
| ToolType | 是 | String | 沙箱工具类型，目前支持：browser、code-interpreter、custom等 枚举值： * browser： browser * code-interpreter： code-interpreter * mobile： mobile * osworld： osworld * custom： custom * swebench： swebench * aio： aio * android-world： android-world * waa： waa 示例值：code-interpreter |
| NetworkConfiguration | 是 | [NetworkConfiguration](https://cloud.tencent.com/document/api/1814/124823#NetworkConfiguration) | 网络配置 |
| Description | 否 | String | 沙箱工具描述，最大长度 200 字符 示例值：代码解释器沙箱工具 |
| DefaultTimeout | 否 | String | 默认超时时间，支持格式：5m、300s、1h 等，不指定则使用系统默认值（5 分钟）。最大 24 小时 示例值：5m |
| Tags.N | 否 | Array of [Tag](https://cloud.tencent.com/document/api/1814/124823#Tag) | 标签规格，为沙箱工具绑定标签，支持多种资源类型的标签绑定 |
| ClientToken | 否 | String | 幂等性 Token，长度不超过 64 字符 示例值：your-unique-client-token |
| RoleArn | 否 | String | 角色ARN 示例值：qcs::cam::uin/100000001:roleName/test_role |
| StorageMounts.N | 否 | Array of [StorageMount](https://cloud.tencent.com/document/api/1814/124823#StorageMount) | 沙箱工具存储配置 |
| CustomConfiguration | 否 | [CustomConfiguration](https://cloud.tencent.com/document/api/1814/124823#CustomConfiguration) | 沙箱工具自定义配置 |
| LogConfiguration | 否 | [LogConfiguration](https://cloud.tencent.com/document/api/1814/124823#LogConfiguration) | 沙箱工具日志推送相关配置 |
| Persistent | 否 | Boolean | 常驻沙箱标识 示例值：false |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| ToolId | String | 创建的沙箱工具 ID 示例值：sdt-dibk4rra |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 4. 示例

### 示例1 创建沙箱工具

#### 输入示例


```
POST / HTTP/1.1
Host: ags.<region>.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: CreateSandboxTool
<公共请求参数>

{
    "ToolName": "browser-sandbox",
    "ToolType": "browser",
    "Description": "浏览器沙箱环境",
    "DefaultTimeout": "30m",
    "NetworkConfiguration": {
        "NetworkMode": "PUBLIC"
    },
    "Tags": [
        {
            "Key": "Environment",
            "Value": "Production"
        },
        {
            "Key": "Team",
            "Value": "AI-Agent"
        }
    ],
    "ClientToken": "unique-token-123"
}
```

#### 输出示例


```json
{
    "Response": {
        "ToolId": "sdt-ee4ywozw",
        "RequestId": "custom-request-id-123"
    }
}
```
