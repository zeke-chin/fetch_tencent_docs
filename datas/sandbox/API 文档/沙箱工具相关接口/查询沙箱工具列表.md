# 查询沙箱工具列表

最近更新时间：2025-11-07 10:12:49


## 1. 接口描述

接口请求域名： ags.tencentcloudapi.com 。

查询沙箱工具列表

默认接口请求频率限制：20次/秒。

 推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=ags&Version=2025-09-20&Action=DescribeSandboxToolList)

 API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](https://cloud.tencent.com/document/api/1814/124827)。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，本接口取值：DescribeSandboxToolList。 |
| Version | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，本接口取值：2025-09-20。 |
| Region | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，详见产品支持的 [地域列表](https://cloud.tencent.com/document/api/1814/124827#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| ToolIds.N | 否 | Array of String | 沙箱工具ID列表，指定要查询的工具。如果为空则查询所有工具。最大支持100个ID 示例值：["sdt-dibk4rra", "sdt-lxoi5oiq"] |
| Offset | 否 | Integer | 偏移量，默认为0 示例值：0 |
| Limit | 否 | Integer | 返回数量，默认为20，最大值为100 示例值：20 |
| Filters.N | 否 | Array of [Filter](https://cloud.tencent.com/document/api/1814/124823#Filter) | 过滤条件 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| SandboxToolSet | Array of [SandboxTool](https://cloud.tencent.com/document/api/1814/124823#SandboxTool) | 沙箱工具列表 |
| TotalCount | Integer | 符合条件的沙箱工具总数 示例值：100 |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 4. 示例

### 示例1 查询沙箱工具列表

#### 输入示例


```
POST / HTTP/1.1
Host: ags.<region>.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeSandboxToolList
<公共请求参数>

{
    "ToolIds": [
        "sdt-ee4ywozw",
        "sdt-another123"
    ]
}
```

#### 输出示例


```json
{
    "Response": {
        "SandboxToolSet": [
            {
                "ToolId": "sdt-ee4ywozw",
                "ToolName": "browser-sandbox",
                "ToolType": "browser",
                "Status": "ACTIVE",
                "Description": "浏览器沙箱环境",
                "Tags": [],
                "CreateTime": "2024-01-15T10:30:00Z",
                "UpdateTime": "2024-01-15T10:30:00Z"
            }
        ],
        "TotalCount": 1,
        "RequestId": "custom-request-id-123"
    }
}
```
