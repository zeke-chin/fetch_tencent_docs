# 查询镜像预热任务信息

最近更新时间：2026-01-14 01:08:09


## 1. 接口描述

接口请求域名： ags.tencentcloudapi.com 。

查询镜像预热任务信息

默认接口请求频率限制：20次/秒。

 推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=ags&Version=2025-09-20&Action=DescribePreCacheImageTask)

 API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](https://cloud.tencent.com/document/api/1814/124827)。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，本接口取值：DescribePreCacheImageTask。 |
| Version | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，本接口取值：2025-09-20。 |
| Region | 是 | String | [公共参数](https://cloud.tencent.com/document/api/1814/124827)，详见产品支持的 [地域列表](https://cloud.tencent.com/document/api/1814/124827#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| Image | 是 | String | 镜像地址 示例值：nginx:latest |
| ImageDigest | 是 | String | 镜像 Digest 示例值：sha256:abcdefg123... |
| ImageRegistryType | 是 | String | 镜像仓库类型：`enterprise`、`personal`。 示例值：enterprise |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| Image | String | 镜像地址 示例值：nginx:latest |
| ImageDigest | String | 镜像 Digest 示例值：sha256:abcdefg123... |
| ImageRegistryType | String | 镜像仓库类型：`enterprise`、`personal`。 示例值：enterprise |
| Status | String | 镜像预热状态 示例值：Success |
| Message | String | 镜像预热状态描述 示例值：镜像预热成功 |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 4. 示例

### 示例1 查询预热任务状态

#### 输入示例


```
POST / HTTP/1.1
Host: ags.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribePreCacheImageTask
<公共请求参数>

{
    "Image": "test.tencentcloudcr.com/example/app:0.2.2",
    "ImageDigest": "sha256:39e2c18395c3105fce919dasdqwe85cd775d380e83581b132d8d742761123a1e675",
    "ImageRegistryType": "enterprise"
}
```

        "ImageRegistryType": "enterprise",
