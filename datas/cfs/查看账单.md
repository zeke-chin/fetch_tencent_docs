# 查看账单

最近更新时间：2025-05-29 11:13:22


文件存储（Cloud File Storage，CFS）服务账单分为资源账单和明细账单，本文为您介绍如何在控制台查看文件存储账单。

## 操作步骤

1. 登录腾讯云控制台，进入 [费用中心](https://console.cloud.tencent.com/expense/overview)。

2. 在左侧导航栏中，选择**成本管理**>**消耗账单**，进入资源 ID 账单管理页面。

3. 在上方的导航栏中，根据实际统计的需要在选择对应的月份。选择**资源账单**，并在**产品名称**中选择**文件存储 CFS**。

**说明：**

资源账单是基于资源的 ID 维度，按月对计费项进行汇总，适合快速的查看资源的消费情况。

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/fb8c5c1f6b9d8a3e4db00fc4a323229e.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/fb8c5c1f6b9d8a3e4db00fc4a323229e.png)

4. 选择**明细账单**，并在**产品名称**中选择**文件存储 CFS**。

**说明：**

明细账单包含每小时的扣费记录，通常整体数量较大，需要通过下载明细的方式详细查看，适用于对统计精细度要求较高的场景。
