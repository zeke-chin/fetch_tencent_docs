# 使用限制

最近更新时间：2026-06-26 18:02:30


## 限制说明

相关限制类型说明如下表所示：

限制类型 限制说明
支持的文件系统类型 数据检索功能仅支持 Turbo 系列文件系统，且需 [提交工单](https://console.cloud.tencent.com/workorder/category) 申请开白使用。
首次全量扫描 使用前需确保文件系统已完成首次全量扫描，否则检索结果可能不准确
检索策略绑定数量 每个文件系统可创建的检索策略数量暂无硬性限制，建议按业务场景合理创建
定期执行最小粒度 定期执行以小时为最小粒度
文件清单有效期 数据清单下载链接保留7天，超期后需重新执行任务获取

## 注意事项

条件生成器和 SQL 模式切换时，已配置的条件不会自动转换，需要重新输入。

使用 SQL 模式时，请确保语法正确，否则任务执行会失败。常见失败原因如下：

SQL 语法错误：请检查 SQL 语句中的关键字和操作符是否正确。

路径格式错误：目录路径需以 `/cfs/` 开头、`*` 结尾。

文件系统未完成全量扫描：请等待扫描完成后再执行。

默认文件大小单位为字节（B），检索策略详情页中，检索任务聚合统计结果会自动将单位转换为 KiB/MiB/GiB。建议您手写 SQL 语句时不要修改 `totalsize=sum(size)`，避免聚合统计结果的单位转换错误。

文件系统 ID 创建后不可修改。如需更换目标文件系统，请新建检索策略。

删除策略后，历史任务记录同步清除，请谨慎操作。

如仍无法解决问题，请 [提交工单](https://console.cloud.tencent.com/workorder/category) 联系 CFS 工程师提供技术支持。
