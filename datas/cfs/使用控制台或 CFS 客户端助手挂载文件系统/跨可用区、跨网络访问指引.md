# 跨可用区、跨网络访问指引

最近更新时间：2026-07-07 12:08:30


## 私有网络下跨可用区访问

当您有多台云服务器（Cloud Virtual Machine，CVM）分布在同地域的不同可用区下，但是又需要共享文件存储（Cloud File Storage，CFS）时，您可以把这些 CVM 和 CFS 设置在同一个 VPC 下，即可实现跨可用区资源的互访。

### 操作场景

以广州为例，若已经有广州五区的云服务器，此时需要用到通用标准型 CFS，但广州五区由于资源有限，暂未开放通用标准型售卖，无法直接创建文件系统。

### 操作步骤

1. 登录 [私有网络子网控制台](https://console.cloud.tencent.com/vpc/subnet?rid=1)，为该 VPC 创建可用区为“广州三区”的子网。

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/c9b7c6b81da089484412e3d759f390db.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/c9b7c6b81da089484412e3d759f390db.png)

2. 创建子网完成后，回到 CFS 控制台，创建广州三区的资源时选择该 VPC 及刚创建的子网。

3. 挂载文件系统。此时原来在该 VPC 广州五区子网下的云服务器即可直接挂载 CFS。

**说明：**

挂载操作详情请参见 [在 Linux 客户端上使用 CFS 文件系统](https://cloud.tencent.com/document/product/582/11523)。

### 跨可用区访问带宽优化方案（可选）

#### 现象与原因

在业务进行跨可用区访问时，常会遇到实际传输带宽显著低于预期的问题。其核心根因在于高延迟环境下的连锁反应：

**延迟误判触发冗余重传**：跨区网络的高延迟，易使客户端误判为网络丢包，从而触发大量冗余的数据重传请求。

**无效流量加剧链路拥塞**：无意义的重复数据包，占据了本已有限的跨区带宽，导致链路拥塞。

**资源利用率与传输效率双低**：网络带宽被无效流量充斥，有效数据的传输路径受阻，致使资源利用率低下，业务传输速度受损。

#### 优化策略

**注意：**

此操作需要客户端内核版本在 4.9 以上。

针对上述高延迟、低吞吐的跨区传输场景，建议将客户端的网络拥塞控制算法从传统的 CCA 切换为 BBR。BBR 算法在该场景下能有效避免因延迟误判导致的冗余重传，显著提升带宽利用率和传输效率。

#### 临时调整为 BBR 算法（重启服务器恢复原配置）

1. 执行以下命令，临时调整 TCP 配置参数：

# 调整发送缓冲区大小

sysctl -w net.ipv4.tcp_wmem="4096 16384 16777216"

# 调整最大发送缓冲区

sysctl -w net.core.wmem_max=8388608

# 设置队列调度算法为 FQ

sysctl -w net.core.default_qdisc=fq

# 设置拥塞控制算法为 BBR

sysctl -w net.ipv4.tcp_congestion_control=bbr

2. 使用以下命令主动断开并重建连接，观察性能是否提升：

# 执行约 5 秒后按 Ctrl+C 中断

tcpkill -i any host {cfsvip}

**注意：**

执行 tcpkill 期间会短暂中断 IO 操作，请在业务低峰期操作。

#### 永久调整为 BBR 算法

1. 编辑系统配置文件。

vim /etc/sysctl.conf

2. 在 `/etc/sysctl.conf` 中添加或修改以下配置项：

net.ipv4.tcp_wmem = 4096 16384 16777216

net.core.wmem_max = 8388608

net.core.default_qdisc=fq

net.ipv4.tcp_congestion_control=bbr

3. 保存退出后，执行以下命令使配置生效：

sysctl -p

## 跨私有网络及跨地域访问

### 适用场景

当您的业务存在以下访问场景，可使用云联网服务达到访问文件存储 CFS 目的：

多台云服务器（CVM）位于不同私有网络（VPC），但需要共同访问同一份文件存储。

云服务器（CVM）与文件存储（CFS）不在同一个私有网络（VPC）内。

云服务器（CVM）与文件存储（CFS）部署在不同的地域。

**注意:**

为保证最佳的访问速度，建议将 CVM 与 CFS 部署在同一可用区。

### 解决方案

您可以通过“**云联网**”服务，将分散在不同私有网络（如 VPC-A、VPC-B）中的云服务器，与另一个私有网络（如 VPC-C）中的文件存储连接起来，实现它们之间的互通访问，详情请参见 [云联网快速入门](https://cloud.tencent.com/document/product/877/30804)。如果您遇到跨地域访问时延迟高、传输慢的问题，建议将客户端（云服务器）的网络拥塞控制算法从传统的 CCA 切换为 BBR。BBR 算法在此场景下能有效减少因网络延迟造成的无效重传，从而提升传输速度和带宽利用率。
