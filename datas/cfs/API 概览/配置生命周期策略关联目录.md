# 配置生命周期策略关联目录

最近更新时间：2026-01-21 01:22:32


## 1. 接口描述

接口请求域名： cfs.tencentcloudapi.com 。

配置生命周期策略关联到的目录列表

默认接口请求频率限制：20次/秒。

 推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=cfs&Version=2019-07-19&Action=ApplyPathLifecyclePolicy)

 API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](https://cloud.tencent.com/document/api/582/38148)。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，本接口取值：ApplyPathLifecyclePolicy。 |
| Version | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，本接口取值：2019-07-19。 |
| Region | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，详见产品支持的 [地域列表](https://cloud.tencent.com/document/api/582/38148#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| LifecyclePolicyID | 是 | String | 生命周期管理策略ID 示例值：policy-xxxxxx |
| Paths.N | 否 | Array of [PathInfo](https://cloud.tencent.com/document/api/582/38175#PathInfo) | 生命周期管理策略关联目录的绝对路径列表 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| CheckResults | Array of [CheckResult](https://cloud.tencent.com/document/api/582/38175#CheckResult) | 有规则冲突时返回的已有冲突规则信息 注意：此字段可能返回 null，表示取不到有效值。 |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 4. 示例

### 示例1 配置生命周期策略关联目录

#### 输入示例


```
https://cfs.tencentcloudapi.com/?Action=ApplyPathLifecyclePolicy
&LifecyclePolicyID=policy-ek8aw4id
&Paths.0.FileSystemId=cfs-4030acd30
&Paths.0.Path=/data
&<公共请求参数>
```

## 6. 错误码

以下仅列出了接口业务逻辑相关的错误码，其他错误码详见 [公共错误码](https://cloud.tencent.com/document/api/582/38176#.E5.85.AC.E5.85.B1.E9.94.99.E8.AF.AF.E7.A0.81)。

| 错误码 | 描述 |
| --- | --- |
| InvalidParameterValue.BindInfrequentaccessFirst | 参数值错误: 绑定归档规则前需绑定沉降规则 |
| InvalidParameterValue.ExternalStorageSupportDataflowOnly | ExternalStorage 生命周期模式只支持数据流动 |
| InvalidParameterValue.InvalidPolicyFsPath | 目录路径中包含无效字符。 |
| InvalidParameterValue.PathUsedInDataflow | 该文件系统目录已配置数据流动，请配置其他规则 |
| ResourceInsufficient.PolicyFsLimitExceeded | 策略绑定文件系统数量超过限制。 |
| ResourceInsufficient.PolicyFsPathLimitExceeded | 策略绑定路径数量超过限制。 |
| ResourceInsufficient.PolicyLimitExceeded | 该用户的生命周期策略个数达到最大限制。 |
| UnsupportedOperation | 操作不支持。 |
