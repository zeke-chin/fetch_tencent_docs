# 创建数据流动

最近更新时间：2025-12-22 01:22:51


## 1. 接口描述

接口请求域名： cfs.tencentcloudapi.com 。

创建数据流动接口

默认接口请求频率限制：20次/秒。

 推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=cfs&Version=2019-07-19&Action=CreateDataFlow)

 API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](https://cloud.tencent.com/document/api/582/38148)。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，本接口取值：CreateDataFlow。 |
| Version | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，本接口取值：2019-07-19。 |
| Region | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，详见产品支持的 [地域列表](https://cloud.tencent.com/document/api/582/38148#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| FileSystemId | 是 | String | 文件系统 ID ，通过查询文件系统 [DescribeCfsFileSystems](https://cloud.tencent.com/document/product/582/38170) 获取 示例值：cfs-4abkgaga |
| SourceStorageType | 是 | String | 源端数据类型；包含S3_COS，S3_L5 示例值：S3_COS |
| SourceStorageAddress | 是 | String | 源端存储地址 示例值：https://cfs-test-1251000014.cos.ap-shanghai.myqcloud.com |
| SourcePath | 是 | String | 源端路径 示例值：/cos/test |
| TargetPath | 是 | String | 文件系统内目标路径 示例值：/cfs/12a3 |
| SecretId | 是 | String | 密钥 ID 示例值：asafsafsa |
| SecretKey | 是 | String | 密钥 key 示例值：ssafsafas |
| DataFlowName | 否 | String | 数据流动名称；支持不超过64字符长度，支持中文、数字、_、- 示例值：default |
| AutoRefresh | 否 | Integer | 0：不开启自动更新 1：开启自动更新 示例值：0 |
| UserKafkaTopic | 否 | String | KafkaConsumer 消费时使用的Topic参数 示例值：1251000004-e37d71b2-4fb1-4b2c-b7d0-522946d17d93 |
| ServerAddr | 否 | String | 服务地址 示例值：kafkaconsumer-ap-beijing.cls.tencentyun.com:9095 示例值：kafkaconsumer-ap-beijing.cls.tencentyun.com:9095 |
| UserName | 否 | String | Kafka消费用户名.示例值：name 示例值：name |
| Password | 否 | String | Kafka消费用户密码。默认${SecretId}#${SecretKey}。 示例值：xbxcxdxexcxdxa |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| DataFlowId | String | 数据流动管理 ID 示例值：cfs-dataflow-abcdefgh |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 4. 示例

### 示例1 创建数据流动

#### 输入示例

```
POST / HTTP/1.1
Host: cfs.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: CreateDataFlow
<公共请求参数>

{
    "FileSystemId": "cfs-44d53b63e",
    "SourceStorageType": "S3_COS",
    "SourceStorageAddress": "https://aileen-data-flow-1251000004.cos.ap-guangzhou.myqcloud.com",
    "SourcePath": "test3",
    "TargetPath": "/cfs/test11",
    "SecretId": "AKIDbzzYj65vue75sC1yg8P4cyBHBpLk",
    "SecretKey": "onE8m9NN82ik6h3FCvXt2uc3Sjp",
    "DataFlowName": "abctest"
}
```

#### 输出示例

```json
{
    "Response": {
        "DataFlowId": "cfs-dataflow-4f827203",
        "RequestId": "c5369436-a47c-4504-9cfa-f1f40c2c969f"
    }
}
```

| InvalidParameterValue.InvalidDataFlowSourceStorageType | 参数值错误：数据流动源存储类型无效 |
| InvalidParameterValue.InvalidDataFlowTargetPath | 参数值错误：数据流动目标路径无效 |
