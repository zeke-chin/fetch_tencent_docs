# 设置文件系统配额

最近更新时间：2025-11-18 01:14:21


## 1. 接口描述

接口请求域名： cfs.tencentcloudapi.com 。

设置文件系统配额，提供UID/GID的配额设置的接口（仅部分Turbo实例能使用，若需要调用请提交工单与我们联系）

默认接口请求频率限制：20次/秒。

 推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=cfs&Version=2019-07-19&Action=SetUserQuota)

 API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](https://cloud.tencent.com/document/api/582/38148)。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，本接口取值：SetUserQuota。 |
| Version | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，本接口取值：2019-07-19。 |
| Region | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，详见产品支持的 [地域列表](https://cloud.tencent.com/document/api/582/38148#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| FileSystemId | 是 | String | 文件系统 ID,通过[查询文件系统列表](https://cloud.tencent.com/document/api/582/38170)获取 示例值：cfs-abc12345 |
| UserType | 是 | String | 指定配额类型，包括Uid、Gid，Dir，分别代表用户配额，用户组配额，目录配额 示例值：Uid |
| UserId | 否 | String | UID/GID信息 示例值：1000 |
| CapacityHardLimit | 否 | Integer | 容量硬限制，单位GiB。设置范围10-10000000。 示例值：10 |
| FileHardLimit | 否 | Integer | 文件硬限制，单位个。设置范围1000-100000000 示例值：10000 |
| DirectoryPath | 否 | String | 需设置目录配额的目录绝对路径，不同目录不可存在包含关系 示例值：/cfs/xx |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| UserId | String | UID/GID信息 示例值：10000 |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 4. 示例

### 示例1 设置文件系统用户配额

用于设置用户配额

#### 输入示例


```
POST / HTTP/1.1
Host: cfs.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: SetUserQuota
<公共请求参数>

{
    "FileSystemId": "cfs-abc12345",
    "UserType": "Uid",
    "UserId": "1000",
    "CapacityHardLimit": 10,
    "FileHardLimit": 10000
}
```

#### 输出示例


```json
{
    "Response": {
        "RequestId": "fjo8aejo-fjei-32eu-2je9-fhue83nd81"
    }
}
```

### 示例2 设置文件系统目录配额

用于设置文件系统目录配额

#### 输入示例


```
POST / HTTP/1.1
Host: cfs.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: SetUserQuota
<公共请求参数>

{
    "FileSystemId": "cfs-abc12345",
    "UserType": "Dir",
    "DirectoryPath": "/cfs/123",
    "CapacityHardLimit": 10,
    "FileHardLimit": 10000
}
```

#### 输出示例


```json
{
    "Response": {
        "RequestId": "fasfsaaejo-fjei-32eu-2je9-fhue83nd81"
    }
}
```

## 6. 错误码

以下仅列出了接口业务逻辑相关的错误码，其他错误码详见 [公共错误码](https://cloud.tencent.com/document/api/582/38176#.E5.85.AC.E5.85.B1.E9.94.99.E8.AF.AF.E7.A0.81)。

| 错误码 | 描述 |
| --- | --- |
| InternalError | 内部错误。 |
| InvalidParameterValue.CfsPath | 无效的文件系统路径 |
| InvalidParameterValue.InvalidPolicyFsPath | 目录路径中包含无效字符。 |
| InvalidParameterValue.ProjectQuotasDirNested | 目录配额设置的目录嵌套 |
| InvalidParameterValue.ProjectQuotasExceeded | 目录配额数量超限 |
| InvalidParameterValue.QuotaCapLimitError | 容量硬限制取值范围错误。 |
| InvalidParameterValue.QuotaFileLimitError | 文件硬限制取值范围错误。 |
| InvalidParameterValue.QuotaUserIdError | USER ID类型错误。 |
| InvalidParameterValue.QuotaUserTypeError | 配额类型错误。 |
| ResourceNotFound | 资源不存在。 |
| ResourceNotFound.FileSystemNotFound | 该文件系统不存在。 |
| UnsupportedOperation | 操作不支持。 |
| UnsupportedOperation.InvalidCfsVersion | 该文件系统版本不支持当前操作 |
