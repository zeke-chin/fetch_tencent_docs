# 查询文件系统配额

最近更新时间：2025-09-12 01:30:53


## 1. 接口描述

接口请求域名： cfs.tencentcloudapi.com 。

查询文件系统配额（仅部分Turbo实例能使用，若需要调用请提交工单与我们联系）

默认接口请求频率限制：20次/秒。

 推荐使用 API Explorer

[点击调试](https://console.cloud.tencent.com/api/explorer?Product=cfs&Version=2019-07-19&Action=DescribeUserQuota)

 API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](https://cloud.tencent.com/document/api/582/38148)。

| 参数名称 | 必选 | 类型 | 描述 |
| --- | --- | --- | --- |
| Action | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，本接口取值：DescribeUserQuota。 |
| Version | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，本接口取值：2019-07-19。 |
| Region | 是 | String | [公共参数](https://cloud.tencent.com/document/api/582/38148)，详见产品支持的 [地域列表](https://cloud.tencent.com/document/api/582/38148#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| FileSystemId | 是 | String | 文件系统 ID,通过[查询文件系统列表](https://cloud.tencent.com/document/api/582/38170)获取 示例值：cfs-abc12345 |
| Filters.N | 否 | Array of [Filter](https://cloud.tencent.com/document/api/582/38175#Filter) | 过滤条件。 UserType - Array of String - 是否必填：否 -（过滤条件）按配额类型过滤。(Uid|Gid|Dir，分别对应用户，用户组，目录 ) UserId- Array of String - 是否必填：否 -（过滤条件）按用户id过滤。 |
| Offset | 否 | Integer | Offset 分页码，默认值0 示例值：0 |
| Limit | 否 | Integer | Limit 页面大小，可填范围为大于0的整数，默认值是10 示例值：10 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| TotalCount | Integer | UserQuota条目总数 示例值：1 |
| UserQuotaInfo | Array of [UserQuota](https://cloud.tencent.com/document/api/582/38175#UserQuota) | UserQuota条目 |
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。 |

## 4. 示例

### 示例1 查询文件系统配额

#### 输入示例


```
POST / HTTP/1.1
Host: cfs.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeUserQuota
<公共请求参数>

{
    "FileSystemId": "cfs-abc12345"
}
```

#### 输出示例


```json
{
    "Response": {
        "UserQuotaInfo": [
            {
                "UserType": "Uid",
                "UserId": "1000",
                "FileSystemId": "cfs-abc12345",
                "CapacityHardLimit": 10,
                "FileHardLimit": 10000,
                "Status": "available",
                "DirectoryPath": "/cfs/abc",
                "CapacityUsed": 1,
                "FileUsed": 1
            }
        ],
        "TotalCount": 1,
        "RequestId": "fjo8aejo-fjei-32eu-2je9-fhue83nd81"
    }
}
```
