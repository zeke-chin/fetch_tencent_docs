## 简介

API 操作名 操作描述
[GET Bucket Object versions](https://cloud.tencent.com/document/product/436/35521)列出对象以及历史版本信息 用于拉取存储桶内的所有对象及其历史版本信息，您可以通过指定参数筛选出存储桶内部分对象及其历史版本信息。

## 查询对象及历史版本

#### 功能说明

列出对象以及历史版本信息（GET Bucket Object versions）。
