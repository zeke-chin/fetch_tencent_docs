# 批量删除

最近更新时间：2024-12-30 10:52:22


## 简介

本文档提供关于对象的批量删除操作相关的 API 概览以及 SDK 示例代码。

API 操作名 操作描述
[DELETE Object](https://cloud.tencent.com/document/product/436/7743)删除多个对象 批量删除指定存储桶中的多个对象

## 删除多个对象

#### 功能说明

删除多个对象（DELETE Multiple Objects）。

#### 示例代码

// 存储桶名称，由 bucketname-appid 组成，appid 必须填入，可以在 COS 控制台查看存储桶名称。 https://console.cloud.tencent.com/cos5/bucket

let bucket = "examplebucket-1250000000";

let request = new DeleteMultipleObjectRequest(bucket);

let objects = new List<DeleteObject>();

objects.add(new DeleteObject("dir/object1"))

objects.add(new DeleteObject("dir/object2"));

request.objects = objects;

try {

 let result = await CosXmlBaseService.default().deleteMultipleObject(request)

 // result中包括http headers等

} catch (e) {

 // 异常处理

}
