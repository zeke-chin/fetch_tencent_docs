## 查询对象元数据

#### 功能说明

查询 Object 的 Meta 信息。

#### 示例代码

// 存储桶名称，由 bucketname-appid 组成，appid 必须填入，可以在 COS 控制台查看存储桶名称。 https://console.cloud.tencent.com/cos5/bucket

let bucket = "examplebucket-1250000000";

//对象在存储桶中的位置标识符，即称对象键

let cosPath = "exampleobject.txt";

let request = new HeadObjectRequest(bucket, cosPath);try { let result = await CosXmlBaseService.default().headObject(request) // result中包括http headers, x-cos-meta-*开头的header就是Object 的 Meta 信息。} catch (e) { // 异常处理}
