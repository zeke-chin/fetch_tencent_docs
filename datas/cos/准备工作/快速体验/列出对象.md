## 列出对象

#### 功能说明

列出该存储桶内的部分或者全部对象（List Object）。

#### 示例代码

// 存储桶名称，由 bucketname-appid 组成，appid 必须填入，可以在 COS 控制台查看存储桶名称。 https://console.cloud.tencent.com/cos5/bucket

let bucket = "examplebucket-1250000000";

let request = new ListObjectsRequest(bucket);

// 获取dir目录下所有文件：request.prefix = "dir/"

// 获取根目录下所有文件：request.prefix = ""；

request.prefix = "dir/"

try {

 let result = await CosXmlBaseService.default().listObject(request)

 // result中包括http headers等

} catch (e) {

 // 异常处

 // 理

}
