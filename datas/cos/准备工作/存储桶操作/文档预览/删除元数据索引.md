## 删除元数据索引

#### 功能说明

从数据集内删除一个文件的元信息。无论该文件的元信息是否在数据集内存在，均会返回删除成功。

**注意：**

COS Android SDK 版本需要大于等于 v5.9.30。

#### 示例代码

// APPID

String appid = "1253000000";

DeleteFileMetaIndexRequest request = new DeleteFileMetaIndexRequest(appid);

DeleteFileMetaIndex deleteFileMetaIndex = new DeleteFileMetaIndex();// 删除元数据索引请求体

request.setDeleteFileMetaIndex(deleteFileMetaIndex);// 设置请求

// 设置数据集名称，同一个账户下唯一。;是否必传：是

deleteFileMetaIndex.datasetName = "test";

// 设置资源标识字段，表示需要建立索引的文件地址。;是否必传：是

deleteFileMetaIndex.uRI = "cos://examplebucket-1250000000/test.jpg";

ciService.deleteFileMetaIndexAsync(request, new CosXmlResultListener() {

 @Override

 public void onSuccess(CosXmlRequest request, CosXmlResult cosResult) {

 // result 删除元数据索引的结果

 }

 @Override

 public void onFail(CosXmlRequest request, CosXmlClientException clientException, CosXmlServiceException serviceException) {

 if (clientException != null) {

 clientException.printStackTrace();

 } else {

 serviceException.printStackTrace();

 }

 }

});
