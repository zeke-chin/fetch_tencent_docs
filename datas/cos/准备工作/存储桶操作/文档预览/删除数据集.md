## 删除数据集

#### 功能说明

删除一个数据集（Dataset）。

**注意：**

COS Android SDK 版本需要大于等于 v5.9.30。

#### 示例代码

// APPID

String appid = "1253000000";

DeleteDatasetRequest request = new DeleteDatasetRequest(appid);

DeleteDataset deleteDataset = new DeleteDataset();// 删除数据集请求体

request.setDeleteDataset(deleteDataset);// 设置请求

// 设置数据集名称，同一个账户下唯一。;是否必传：是

deleteDataset.datasetName = "test";

ciService.deleteDatasetAsync(request, new CosXmlResultListener() {

 @Override

 public void onSuccess(CosXmlRequest request, CosXmlResult cosResult) {

 // result 删除数据集的结果

 // 详细字段请查看api文档或者SDK源码

 DeleteDatasetResult result = (DeleteDatasetResult) cosResult;

 }

 @Override

 public void onFail(CosXmlRequest request, CosXmlClientException clientException, CosXmlServiceException serviceException) {

 if (clientException != null) {

 clientException.printStackTrace();

 } else {

 serviceException.printStackTrace();

 }

 }

});
