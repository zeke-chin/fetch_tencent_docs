## 宠物识别

#### 功能说明

腾讯云数据万象通过 detect-pet 接口识别并输出画面中宠物，输出其位置（矩形框）和置信度。图片宠物识别请求包属于 GET 请求，请求时需要携带签名。

#### 返回结果说明

response 为响应头，data 为宠物识别结果，数据类型都为 dict。

##### response内容

返回公共响应头部，详情请参见 [公共响应头部](https://cloud.tencent.com/document/product/460/42866) 文档。

##### 响应体data

由于接口默认返回xml内容，解析结果都为string类型，以下描述为字段的真实类型。具体数据内容如下：

参数名称 参数描述 类型
ResultInfo 保存结果的容器 Container Array

ResultInfo 节点内容：

参数名称 参数描述 类型
Score 分数，范围在0-100之间，值越高，表示目标为相应结果的可能性越高 Integer
Name 宠物名称 String
Location 保存宠物位置的容器 Container

Location 节点内容：

参数名称 参数描述 类型
X x轴坐标 Integer
Y y轴坐标 Integer
Height(x,y)坐标距离高度 Integer
Width(x,y)坐标距离长度 Integer
