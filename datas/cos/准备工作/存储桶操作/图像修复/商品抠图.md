## 商品抠图

#### 功能说明

腾讯云数据万象通过 GoodsMatting 接口检测图片中的商品信息，生成只包含商品信息的图片，支持持久化、云上处理及下载时处理。

#### 示例代码

#### 参数说明

调用 cos_goods_matting 函数，具体请求参数如下：

参数名称 参数描述 类型 是否必填
Bucket 存储桶名称 String 是
ObjectKey 设置对象名称。ObjectKey与DetectUrl必选一个 String 否
DetectUrl 您可以通过填写 detect-url 处理任意公网可访问的图片链接。不填写 detect-url 时，后台会默认处理 ObjectKey ，填写了 detect-url 时，后台会处理 detect-url 链接，无需再填写 ObjectKey。detect-url 示例：`http://www.example.com/abc.jpg`，需要进行 UrlEncode，处理后为 `http%25253A%25252F%25252Fwww.example.com%25252Fabc.jpg`。ObjectKey与DetectUrl必选一个 String 否
CenterLayout 抠图商品居中显示； 值为1时居中显示，值为0时不作处理，默认为0 Int 否
PaddingLayout 将处理后的图片四边进行留白，形式为 padding-layout=<dx>x<dy>，左右两边各进行 dx 像素的留白，上下两边各进行 dy 像素的留白，例如：padding-layout=20x10，默认不进行留白操作，dx、dy最大值为1000像素 String 否
Stream 是否以流式方式接收响应内容，默认为 True Boolean 否
