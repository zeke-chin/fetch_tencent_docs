## 图片上色

#### 功能说明

腾讯云数据万象通过 AIImageColoring 接口对黑白图像进行上色

#### 示例代码

def cos_ai_image_coloring():

 # 图片上色

 response, data = client.cos_ai_image_coloring(

 Bucket=bucket_name, ObjectKey="test.jpeg", # DetectUrl="https://test-125000000.cos.ap-chongqing.myqcloud.com/test.jpeg" Stream=True

 )

 data.get_stream_to_file('result.jpg') print(response) return response, data

#### 参数说明

调用 cos_ai_image_coloring 函数，具体请求参数如下：

参数名称 参数描述 类型 是否必填
Bucket 存储桶名称 String 是
ObjectKey 数据万象处理能力，图片上色参固定为AIImageColoring。String 否
DetectUrl 待上色图片url，与ObjectKey二选其一，如果同时存在，则默认以ObjectKey为准 String 否
Stream 是否以流式方式接收响应内容，默认为True Boolean 否

#### 返回结果说明

response 为响应头， 数据类型为 dict。 data 为图片上色处理后的图片。

##### response内容

返回公共响应头部，详情请参见 [公共响应头部](https://cloud.tencent.com/document/product/460/42866) 文档。
