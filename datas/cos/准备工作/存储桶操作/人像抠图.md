# 人像抠图

最近更新时间：2025-11-11 14:56:32


## 简介

本文档提供关于人像抠图的相关 API 概览以及 SDK 示例代码。

API 操作描述
[人像抠图](https://cloud.tencent.com/document/product/460/106751)腾讯云数据万象通过 AIPortraitMatting 接口检测图片中的人像主体信息，智能分割图像背景，生成只包含人像主体信息的图片，支持持久化、云上处理及下载时处理。

## SDK API 参考

SDK 所有接口的具体参数与方法说明，请参考 [SDK API](https://cos-android-sdk-doc-1253960454.file.myqcloud.com/)。

## 功能说明

腾讯云数据万象通过 AIPortraitMatting 接口检测图片中的人像主体信息，智能分割图像背景，生成只包含人像主体信息的图片，支持持久化、云上处理及下载时处理。

**注意：**

COS Android SDK 版本需要使用 v5.9.47及以上版本。

## 示例代码

// 存储桶名称，格式为 BucketName-APPID

String bucket = "examplebucket-1250000000";

AIPortraitMattingRequest request = new AIPortraitMattingRequest(bucket, "folder/PortraitMatting.jpg");

// 抠图主体居中显示

request.centerLayout = true;

// 将处理后的图片四边进行留白

request.paddingLayout = "10 x 10";

// 设置结果文件保存路径

request.saveLocalPath = "保存到本地的路径";

cosXmlService.aiPortraitMattingAsync(request, new CosXmlResultListener() {

 // result 人像抠图的结果

 }

 public void onFail(CosXmlRequest request, CosXmlClientException clientException, CosXmlServiceException serviceException) {

 if (clientException != null) {

 clientException.printStackTrace();

 } else {

 serviceException.printStackTrace();

 }

 }

});
