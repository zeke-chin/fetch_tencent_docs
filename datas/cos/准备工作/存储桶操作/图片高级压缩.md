# 图片高级压缩

最近更新时间：2025-06-30 12:01:32


## 简介

本文档提供关于图片高级压缩的 API 概览以及 SDK 示例代码。

API 操作描述
[图片高级压缩](https://cloud.tencent.com/document/product/436/48987)对指定存储桶下的图片进行压缩

## 图片高级压缩

#### 功能说明

通过数据万象 imageMogr2 接口提供图片高级压缩功能。

**说明：**

使用图片高级压缩，需在控制台先开通图片高级压缩服务，详情请参见 [操作指引](https://cloud.tencent.com/document/product/460/46821)。

腾讯云数据万象提供集成 TPG、AVIF 解码器的 [iOS](https://cloud.tencent.com/document/product/460/47729)、[Android](https://cloud.tencent.com/document/product/460/47734)、[Windows](https://ci-document-example-1259788808.cos.ap-shanghai.myqcloud.com/TPG_win_SDK_2023.zip) 终端 SDK，您只需在您的客户端进行集成，即可实现对 TPG 和 AVIF 的解码预览。

#### 方法原型

ci_download_compress_image(self, Bucket, Key, DestImagePath, CompressType, **kwargs)

#### 请求示例

# TPG 压缩

response = client.ci_download_compress_image(

 Bucket='examplebucket-1250000000',

 Key='sample.png',

 DestImagePath='sample.tpg',

 CompressType='tpg'

)

# HEIF 压缩

response = client.ci_download_compress_image(

 Bucket='examplebucket-1250000000',

 Key='sample.png',

 DestImagePath='sample.heif',

 CompressType='heif'

)

# AVIF 压缩

response = client.ci_download_compress_image(

 Bucket='examplebucket-1250000000',

 Key='sample.png',

 DestImagePath='sample.heif',

 CompressType='avif'

)

# SVG 压缩

response = client.ci_download_compress_image(

 Bucket='examplebucket-1250000000',

 Key='sample.png',

 DestImagePath='sample.heif',

 CompressType='svg'

)

#### 参数说明

参数名称 参数描述 类型 是否必填
Bucket 存储桶名称，格式为 BucketName-APPID ，详情请参见 [命名规范](https://cloud.tencent.com/document/product/436/13312#.E5.AD.98.E5.82.A8.E6.A1.B6.E5.91.BD.E5.90.8D.E8.A7.84.E8.8C.83)String 是
Key 对象Key，长度不超过128字节, 支持英文字母、数字、空格、加号、减号、下划线、等号、点号、冒号、斜线 String 是
DestImagePath 压缩图片保存至本地的目的路径 String 是
CompressType 压缩格式，支持 tpg heif avif svg String 是

#### 返回结果说明

返回公共响应头部，详情请参见 [公共响应头部](https://cloud.tencent.com/document/product/436/7729) 文档。
