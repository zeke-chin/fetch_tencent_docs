## 游戏场景识别

#### 功能说明

游戏标签功能实现游戏图片场景的识别，返回图片中置信度较高的游戏类别标签。游戏标签识别请求包属于 GET 请求，请求时需要携带签名。

#### 参数说明

调用 cos_ai_game_rec 函数，具体请求参数如下：

参数名称 参数描述 类型 是否必填
Bucket 存储桶名称 String 是
ObjectKey 图片地址。ObjectKey与DetectUrl必选一个 String 否
DetectUrl 您可以通过填写 detect-url 对任意公网可访问的图片进行游戏场景识别。不填写 detect-url 时，后台会默认处理 objectkey ；填写了 detect-url 时，后台会处理 detect-url 链接，无需再填写 objectkey ， detect-url 示例：`http://www.example.com/abc.jpg` ，需要进行 UrlEncode，处理后为 `http%25253A%25252F%25252Fwww.example.com%25252Fabc.jpg`。ObjectKey与DetectUrl必选一个 String 否

#### 返回结果说明

response 为响应头，data 为游戏场景识别结果，数据类型都为 dict。

##### response内容

返回公共响应头部，详情请参见 [公共响应头部](https://cloud.tencent.com/document/product/460/42866) 文档。

##### 响应体data

由于接口默认返回xml内容，解析结果都为string类型，以下描述为字段的真实类型。具体数据内容如下：

参数名称 参数描述 类型
GameLabels 游戏标签信息 Container

GameLabels 节点内容：

参数名称 参数描述 类型
Confidence 该标签的置信度分数，分数越高则该标签准确度越高 Integer
FirstCategory 一级标签 String
SecondCategory 二级标签 String
GameName 识别出的游戏标签名称 String
