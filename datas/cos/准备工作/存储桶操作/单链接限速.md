# 单链接限速

最近更新时间：2024-08-14 14:20:22


## 简介

本文介绍对象存储 COS 通过小程序 SDK 实现调用上传下载接口时对链接进行限速功能的示例代码和描述。

## 注意事项

限速值设置范围为**819200 - 838860800**，单位默认为 bit/s，即800Kb/s - 800Mb/s，如果超出该范围将返回400错误。

**说明：**

关于单链接限速的更多说明，请参见 [单链接限速](https://cloud.tencent.com/document/product/436/40140 "https://cloud.tencent.com/document/product/436/40140") 开发者指南。

## 前期准备

开始使用前，确保您已经完成了 [白名单配置](https://cloud.tencent.com/document/product/436/31953#.E5.B0.8F.E7.A8.8B.E5.BA.8F.E5.9F.9F.E5.90.8D.E7.99.BD.E5.90.8D.E5.8D.95.E9.85.8D.E7.BD.AE) 并完成了 [SDK 初始化](https://cloud.tencent.com/document/product/436/31953)。

## 使用案例

### 上传时对单链接限速

cos.uploadFile({

 Bucket: 'examplebucket-1250000000', // 填入您自己的存储桶，必须字段

 Region: 'COS_REGION', // 存储桶所在地域，例如ap-beijing，必须字段

 Key: '1.jpg', // 存储在桶里的对象键（例如1.jpg，a/b/test.txt），必须字段

 FilePath: file.path, // 必须

 FileSize: file.size, // v1.4.3之前的版本必须，v1.4.3及以后的版本非必须

 Body: fileObject, // 上传文件对象

 Headers: {

 'x-cos-traffic-limit': 819200, // 限速值设置范围为819200 - 838860800，单位默认为 bit/s，即800Kb/s - 800Mb/s，如果超出该范围将返回400错误。

 },

 onProgress: function(progressData) {

 console.log(JSON.stringify(progressData));

 }

}, function(err, data) {

 console.log(err || data);

});
