# 删除元数据索引

最近更新时间：2025-06-17 20:13:52


## 简介

本文档提供关于删除元数据索引的相关 API 概览以及 SDK 示例代码。

API 操作描述
[删除元数据索引](https://cloud.tencent.com/document/product/460/106163)删除元数据索引

## 功能说明

从数据集内删除一个文件的元信息。无论该文件的元信息是否在数据集内存在，均会返回删除成功。
