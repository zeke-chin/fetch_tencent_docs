# 创建工作流

最近更新时间：2025-01-10 17:04:22


## 简介

创建工作流功能是由 [数据万象](https://cloud.tencent.com/document/product/460)（Cloud Infinite，CI）提供的，数据万象将处理能力与 COS SDK 完全结合，您可以直接按照本篇文档指引进行使用。 本文档提供关于创建工作流的相关 API 概览以及 SDK 示例代码。

**注意：**

COS Javascript SDK 版本需要大于等于 v1.3.1。

API 操作描述
[创建工作流](https://cloud.tencent.com/document/product/460/76856)创建工作流

## 创建工作流

#### 功能说明

创建工作流。
