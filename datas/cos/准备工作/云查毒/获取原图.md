## 获取原图

#### 功能说明

如果您开启了图片原图保护功能，同时在某些场景下希望获取到原图，可通过本接口进行获取。

#### 使用示例

function getOriginImage() {

 // sdk引入以及初始化请参考：https://cloud.tencent.com/document/product/436/31953

 const config = {

 // 需要替换成您自己的存储桶信息

 Bucket: 'examplebucket-1250000000', // 存储桶，必须字段

 Region: 'COS_REGION', // 存储桶所在地域，必须字段 如 ap-beijing

 };

 const ObjectKey = "test.jpg";

 const key = `${ObjectKey}` // ObjectKey:{ObjectKey};

 const host = `${config.Bucket}.cos.${config.Region}.myqcloud.com`;

 const url = `https://${host}/${key}`;


 cos.request(

 {

 Method: 'GET', // 固定值，必须

 Key: key, // 必须

 Url: url, // 请求的url，必须

 Query: {

 // 万象通用参数，需要获取原图的时，该参数固定为：originImage;是否必传：是

 "ci-process": "originImage",

 },

 },

 function (err, data) {

 if (err) {

 // 处理请求失败

 console.log(err);

 } else {

 // 处理请求成功

 console.log(data.Response);

 }

 },

 );

}

getOriginImage()

Key{ObjectKey}String 是
Query 请求参数 Object 否

参数名称 参数描述 类型 是否必填
