# 删除数据集

最近更新时间：2024-07-18 16:51:22


## 简介

删除数据集功能是由 [数据万象](https://cloud.tencent.com/document/product/460)（Cloud Infinite，CI）提供的，数据万象将处理能力与 COS SDK 完全结合，您可以直接按照本篇文档指引进行使用。 本文档提供关于删除数据集的相关 API 概览以及 SDK 示例代码。

**注意：**

COS 小程序 SDK 版本需要大于等于 v1.7.1。

API 操作描述
[删除数据集](https://cloud.tencent.com/document/product/460/106157)删除一个数据集（Dataset）。

## 删除数据集

#### 功能说明

删除一个数据集（Dataset）。

#### 使用示例

function deleteDataset() {

 // sdk引入以及初始化请参考：https://cloud.tencent.com/document/product/436/31953

 const config = {

 // 需要替换成您自己的存储桶信息

 AppId: '1250000000', // AppId，必须字段

 Region: 'COS_REGION', // 存储桶所在地域，必须字段 如 ap-beijing

 };

 const key = 'dataset'; // 固定值

 const host = `${config.AppId}.ci.${config.Region}.myqcloud.com`;

 const url = `https://${host}/${key}`;

 const body = JSON.stringify({

 // 自定义数据集名称，同一个账户下唯一。;是否必传：是

 DatasetName: 'test-dataset-base',

 });

 cos.request(

 {

 Method: 'DELETE', // 固定值，必须

 Key: key, // 必须

 Url: url, // 请求的url，必须

 Body: body, // 请求体参数，必须

 Headers: {

 // 设置请求体为 json，固定值，必须

 'Content-Type': 'application/json',

 // 设置响应体为json，固定值，必须

 Accept: 'application/json',

 },

 },

 function (err, data) {

 if (err) {

 // 处理请求失败

 console.log(err.code, err.message);

 } else {

 // 处理请求成功

 console.log(data);

 }

 }

 );

}

deleteDataset()

#### 参数说明

cos.request 方法参数说明：

参数名称 参数描述 类型 是否必填
Method 固定值：DELETE String 是
Key 固定值：dataset String 是
Url 请求 url，固定值 String 是
Body 请求体详情请参见 [删除数据集](https://cloud.tencent.com/document/product/460/106157#.E8.AF.B7.E6.B1.82)Object 是
ContentType 设置请求体为 json，固定值 String 是
Accept 设置响应体为 json，固定值 String 是

#### 回调函数说明

function(err, data) { ... }

参数名称 参数描述 类型
err 请求发生错误时返回的对象，包括网络错误和业务错误。如果请求成功则为空，更多详情请参见 [错误码](https://cloud.tencent.com/document/product/460/8523)Object
- statusCode 请求返回的 HTTP 状态码，例如200、403、404等 Number
- headers 请求返回的头部信息 Object
data 请求成功时返回的对象，如果请求发生错误，则为空 Object
- statusCode 请求返回的 HTTP 状态码，例如200、403、404等 Number
- headers 请求返回的头部信息 Object
- Dataset 数据集信息，详情请参见 [删除数据集](https://cloud.tencent.com/document/product/460/106157#.E5.93.8D.E5.BA.94)Object
- RequestId 请求 ID String
