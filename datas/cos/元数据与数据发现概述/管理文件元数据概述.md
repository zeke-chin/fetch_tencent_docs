# 管理文件元数据概述

最近更新时间：2026-04-01 10:51:42


## 核心能力简介

​数据集的生命周期管理​：数据集用于定义和管理具有相同特征或用途的文件。您可创建、查询、更新、删除数据集。

​数据源关联​：建立实际存储位置与逻辑数据集之间的映射关系。您可将指定的 COS 存储桶与数据集进行绑定或解绑。

​元数据索引管理​：系统可以为数据集内的文件自动或根据配置提取丰富的元数据信息（如 EXIF 信息、媒体文件属性、AI 识别出的标签等）并建立索引。

​检索模板与算子​：提供预置或自定义的检索规则和算法，支持复杂的查询条件，为多场景、跨模态的检索能力提供支持。

## 使用限制

智能检索功能需 [绑定 COS 存储桶](https://cloud.tencent.com/document/product/460/46483) 使用。

地域限制：仅支持绑定北京、上海、成都地域的存储桶，仅支持对北京、上海、成都地域的 COS 文件建立元数据索引。

## 操作步骤

### 控制台方式

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。

2. 在左侧导航栏中，选择**智能检索**>**数据集管理**。

3. 单击**创建数据集**，您可在**绑定数据源**处选择数据源建立关联关系，单击**确定**即可完成数据集创建。

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/ca3af628203ec34f9287abda2873834c.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/ca3af628203ec34f9287abda2873834c.png)

**注意：**

“存量数据索引”选项若在创建数据集阶段未开启，后续将无法开启。

4. 若数据集未绑定数据源，您可单击对应数据集所在行的**管理**，进入数据集后单击**绑定数据源**完成绑定。

![Image 4](https://qcloudimg.tencent-cloud.cn/image/document/b3e1b1fe18f29d792c70b974e106facd.png)

![Image 5](https://qcloudimg.tencent-cloud.cn/image/document/b3e1b1fe18f29d792c70b974e106facd.png)

5. ​完成数据集创建与数据源绑定后，便可使用相关检索功能，若在创建数据集阶段开启了“存量数据索引”选项，请等待“**索引建立完成**”后再使用相关检索功能。

### API 方式

腾讯云提供了 API 接口方便您进行数据集管理，具体操作请参见 [数据集管理](https://cloud.tencent.com/document/product/436/107203)。
