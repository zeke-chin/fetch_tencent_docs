# 取消异步导出任务

最近更新时间：2026-04-07 11:15:05


## 功能描述

本接口支持取消单个异步导出任务。

**说明：**

只有任务状态为 todo(待执行) / running(执行中) 的任务支持取消操作，如需查询所有任务状态可参见 [列出异步导出任务](https://cloud.tencent.com/document/product/460/120574)。

## 授权说明

通过子账号使用时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加 `ci:CancelDatasetExport` 权限，数据万象支持的所有操作接口请参见 [CI action](https://cloud.tencent.com/document/product/598/98114)。

## 服务开通

首次使用该功能将默认为您开通数据万象，并绑定存储桶，无需角色授权，即可直接使用。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

使用该接口时，请先确认相关限制条件。详情请参见 [使用限制](https://cloud.tencent.com/document/product/460/36620#95ae1980-bb63-4c7d-9544-5dc6357d13be)。

## 请求

### 请求示例

DELETE /datasetquery/export HTTP/1.1

Host: <AppId>.ci.<Region>.myqcloud.com

Authorization: Auth String

Content-Length: xxx

Content-Type: application/json

Accept: application/json

**说明：**

Authorization: Auth String（详情请参见 [请求签名](https://cloud.tencent.com/document/product/436/7778) 文档）。
