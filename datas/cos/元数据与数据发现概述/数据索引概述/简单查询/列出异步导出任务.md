# 列出异步导出任务

最近更新时间：2026-04-07 11:16:00


## 功能描述

本接口用于查询智能检索服务下，所有异步导出任务的信息列表。返回结果包括任务 ID、状态、创建时间、进度等详细信息，支持您集中监控和管理所有已提交的检索导出任务。如需查询单个任务可参见 [查询异步导出任务](https://cloud.tencent.com/document/product/460/120573)。

## 授权说明

通过子账号使用时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加 `ci:ListDatasetExport` 权限，数据万象支持的所有操作接口请参见 [CI action](https://cloud.tencent.com/document/product/598/98114)。

## 服务开通

首次使用该功能将默认为您开通数据万象，并绑定存储桶，无需角色授权，即可直接使用。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

使用该接口时，请先确认相关限制条件。详情请参见 [使用限制](https://cloud.tencent.com/document/product/460/36620#95ae1980-bb63-4c7d-9544-5dc6357d13be)。

## 请求

### 请求示例

GET /datasetquery/exports?datasetname=test&maxresults=20&nexttoken=xxxxxx HTTP/1.1

Host: <AppId>.ci.<Region>.myqcloud.com

Date: <GMT Date>

Authorization: Auth String

Accept: application/json

**说明：**

Authorization: Auth String（详情请参见 [请求签名](https://cloud.tencent.com/document/product/436/7778) 文档）。

### 请求头

此接口仅使用公共请求头部，详情请参见 [公共请求头部](https://cloud.tencent.com/document/product/436/7728) 文档。

### 请求参数

具体参数如下：

参数名称 描述 类型 是否必选
DatasetName 数据集名称，同一个账户下唯一 String 是
MaxResults 返回任务列表的最大个数，取值范围为0-200。不设置此参数或者设置为0时，则默认值为100 Integer 否
NextToken 当任务总数大于设置的 MaxResults 时，用于翻页的 token。从 NextToken 开始按字典序返回任务列表。第一次调用此接口时，设置为空 String 否

### 请求体

该请求无请求体。
