# 文件处理

最近更新时间：2025-12-30 10:10:52


## 概述

针对存储在 COS 上的所有文件，提供解压、打包压缩、哈希值计算等文件处理功能，目前支持的处理功能请见下表：

功能 说明
文件解压 支持对压缩包文件进行云上解压，解压后转存至 COS，当前支持的压缩包格式有 zip、tar、rar、gz、7zip、apk。

文件大小限制说明：小于5TB 的文件。
压缩包预览 支持对压缩包文件进行预览，无需解压整个文件即可预览压缩包内的文件数量、大小等，当前支持的压缩包格式有 zip、tar、rar、gz、7zip、apk。

文件大小限制说明：zip/7zip无大小限制，tar/gz/rar/apk需小于128MB。
多文件打包压缩 支持对多个文件进行打包压缩，当前支持打包为 zip、tar、tar.gz 格式。

压缩限制说明：最多支持打包1000万个文件，打包后文件总大小不超过50TB。
哈希值计算 计算文件的哈希值，当前支持的哈希值算法有 MD5、SHA1、SHA256。

文件大小限制说明：

同步请求：小于128MB 的文件。

异步请求限制：小于50GB 的文件。

**说明**

文件处理为收费服务，由数据万象产品提供并收取相关费用，详细的计费说明请参见数据万象 [文件处理费用](https://cloud.tencent.com/document/product/460/82333)。

文件处理当前支持以下地域：公有云下的中国大陆、中国香港、新加坡、硅谷。

## 适用场景

### 数据校验

通过计算文件哈希值，可快速进行数据一致性校验。

### 生活工具

提供 PaaS 云上文件压缩和文件解压功能，文件解压后可在线预览，为用户提供更全面的在线预览场景。

## 使用方法

文件处理功能由数据万象产品提供，您需要先开通数据万象服务，[单击开通](https://console.cloud.tencent.com/ci)。

开通数据万象后，您可以在对象存储控制台上开启文件处理功能，开启后即可通过控制台或 API 接口进行使用。

### 使用对象存储控制台

#### 通过文件列表使用

您可以通过存储桶文件列表中的**更多操作**，对文件进行哈希值计算等文件处理操作，详情请查看 [通过文件列表进行文件处理](https://cloud.tencent.com/document/product/436/82328)。

#### 通过任务使用

您可以通过**任务与工作流**进行文件处理相关的操作，详情请参见 [配置文件解压缩任务](https://cloud.tencent.com/document/product/436/82330)、 [配置多文件打包压缩任务](https://cloud.tencent.com/document/product/436/82331)、[配置文件哈希值任务](https://cloud.tencent.com/document/product/436/82329)。

**注意**

当前仅支持通过任务使用，暂不支持工作流。

### 使用 API 接口

您可以使用我们提供的 API 接口对文件进行哈希值计算等处理，详情请参见以下 API 文档：

[文件解压](https://cloud.tencent.com/document/product/436/83110)

[压缩包预览](https://cloud.tencent.com/document/product/436/93032)

[多文件打包压缩](https://cloud.tencent.com/document/product/436/83112)

[文件哈希值计算](https://cloud.tencent.com/document/product/436/83107)
