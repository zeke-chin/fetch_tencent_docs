# 提交任务

最近更新时间：2025-09-19 15:44:52


## 功能描述

提交一个图片处理任务。

## 授权说明

通过子账号使用时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加对应的权限。数据万象支持的所有操作接口请参见 [CI action](https://cloud.tencent.com/document/product/598/98114)。

使用图片异步处理功能时，需要在授权策略的 action 中添加 `ci:CreateMediaJobs`权限。

使用异步处理接口时，需要在授权策略的 action 中添加 `cam:PassRole` 权限。异步处理接口会通过 CAM 的“角色”进行 COS 的资源读写操作，PassRole 权限用于传递角色， 具体请查看 [访问管理 > 写操作 > PassRole 接口](https://cloud.tencent.com/document/product/598/69872#.E5.86.99.E6.93.8D.E4.BD.9C)。

## 服务开通

使用该功能需提前 [绑定存储桶](https://cloud.tencent.com/document/product/460/46483)，开通数据万象服务。

使用该功能需提前通过 [接口](https://cloud.tencent.com/document/product/460/95749) 开通图片处理（异步）服务。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

使用该接口时，请先确认相关限制条件。详情请参见 [使用限制](https://cloud.tencent.com/document/product/460/36620#Image-processing)。

## 费用说明

该接口为付费服务，产生的费用将由数据万象收取，详细计费说明可参见 [图片处理费用](https://cloud.tencent.com/document/product/460/58117)。

Container 节点

JobsDetail

 的内容：

节点名称（关键字）父节点 描述 类型
Code Response.JobsDetail 错误码，当 State 为 Failed 时生效 String
Message Response.JobsDetail 错误描述，当 State 为 Failed 时生效 String
JobId Response.JobsDetail 新创建任务的 ID String
Tag Response.JobsDetail 新创建任务的 Tag：PicProcess String
State Response.JobsDetail 任务状态

Submitted：已提交，待执行

Running：执行中

Success：执行成功

Failed：执行失败

Pause：任务暂停，当暂停队列时，待执行的任务会变为暂停状态

Cancel：任务被取消执行 String
CreationTime Response.JobsDetail 任务的创建时间 String
StartTime Response.JobsDetail 任务的开始时间 String

QueueId Response.JobsDetail 任务所属的 [队列 ID](https://cloud.tencent.com/document/product/460/46487)String
