# 视频截帧同步请求

最近更新时间：2025-12-05 15:34:22


## 功能描述

GetSnapshot 接口用于获取媒体文件某个时间的截图。

## 授权说明

通过子账号使用时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加 `ci:GenerateSnapshot` 权限。数据万象支持的所有操作接口请参见 [CI action](https://cloud.tencent.com/document/product/598/98114)。

## 服务开通

使用该功能需提前 [绑定存储桶](https://cloud.tencent.com/document/product/460/46483)，开通数据万象服务。

使用该功能需提前通过 [控制台](https://cloud.tencent.com/document/product/460/87745) 或 [接口](https://cloud.tencent.com/document/product/460/72823) 开通媒体处理服务。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

使用该接口时，请先确认相关限制条件。详情请参见 [使用限制](https://cloud.tencent.com/document/product/460/36620#Media-processing)。

## 费用说明

该接口为付费服务，产生的费用将由数据万象收取，详细计费说明可参见 [媒体处理费用](https://cloud.tencent.com/document/product/460/58120)。

## 请求示例

#### 1. 通过 GET 请求方式

GET /<ObjectKey>?ci-process=snapshot&time=1&format=jpg HTTP/1.1

Host: <BucketName-APPID>.cos.<Region>.myqcloud.com

Date: <GMT Date>

Authorization: <Auth String>

Content-Length: <length>

#### 2. 通过 URL 地址添加参数方式

https://<BucketName-APPID>.cos.<Region>.myqcloud.com/for-test.mp4?ci-process=snapshot&time=1&format=jpg&<Auth String>

**说明：**

Authorization: Auth String，详情请参见 [请求签名](https://cloud.tencent.com/document/product/436/7778) 文档。

ObjectKey 为存储桶对象。

此接口为同步模式，异步模式请参见 [截图任务](https://cloud.tencent.com/document/product/460/84780)。

#### 请求头

此接口仅使用公共请求头部，详情请参见 [公共请求头部](https://cloud.tencent.com/document/product/436/7728) 文档。

#### 请求参数

参数说明如下：

参数名称 描述 类型 是否必选
ci-process 操作类型，固定使用 snapshot String 是
time 截图的时间点，单位为秒 float 是
width 截图的宽。取值范围为 [0, 4096]。默认值为0 Int 否
height 截图的高。取值范围为 [0, 4096]。默认值为0 Int 否
format 截图的格式，支持 jpg 和 png，默认 jpg String 否
rotate 图片旋转方式

auto：按视频旋转信息进行自动旋转

off：不旋转

默认值为 auto String 否
mode 截帧方式

keyframe：截取指定时间点之前的最近的一个关键帧

exactframe：截取指定时间点的帧

默认值为 exactframe String 否

**说明：**

同步视频截帧截取的图片可使用图片基础处理能力，具体参数请参见 [图片基础处理](https://cloud.tencent.com/document/product/460/6924)，相关示例请参见 [实际案例 > 请求3](https://cloud.tencent.com/document/product/460/49283#09613bef-f856-45bf-b6c5-3923a1e59e4a)。

当 width 和 height 都为0时，表示使用视频的宽高。如果单个为0，则以另外一个值按视频宽高比例自动适应。

该请求无请求体。
