# 查询模板

最近更新时间：2025-08-29 15:03:53


## 功能描述

查询模板。

## 授权说明

通过子账号使用时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加 `ci:DescribeMediaTemplates`权限。数据万象支持的所有操作接口请参见 [CI action](https://cloud.tencent.com/document/product/598/98114)。

## 服务开通

使用该功能需提前 [绑定存储桶](https://cloud.tencent.com/document/product/460/46483)，开通数据万象服务。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

使用该接口时，请先确认相关限制条件。详情请参见 [使用限制](https://cloud.tencent.com/document/product/460/36620)。

## 请求

#### 请求示例

GET /template HTTP/1.1

Host: <BucketName-APPID>.ci.<Region>.myqcloud.com

Date: <GMT Date>

Authorization: <Auth String>

Content-Length: <length>

Content-Type: application/xml

**说明：**

Authorization: Auth String ，详情请参见 [请求签名](https://cloud.tencent.com/document/product/436/7778) 文档。

#### 请求头

此接口仅使用公共请求头部，详情请参见 [公共请求头部](https://cloud.tencent.com/document/product/460/42865) 文档。

#### 请求体

该请求的请求体为空。

#### 请求参数

参数的具体内容如下：

节点名称（关键字）父节点 描述 类型 是否必选
tag 无 模板类型，默认值: All String 否
category 无 可选值如下：

Official：系统预设模板

Custom（默认值）：自定义模板 String 否
ids 无 模板 ID，以`,`符号分隔字符串，可在创建模板的响应中获取 String 否
name 无 模板名称前缀 String 否
pageNumber 无 第几页，默认值为1 Integer 否
pageSize 无 每页个数，取值范围为[1, 100]，默认值为10 Integer 否

tag 支持以下几种类型:

模板类型 tag
音视频转码 Transcode
视频转动图 Animation
视频截图 Snapshot
智能封面 SmartCover
音视频拼接 Concat
人声分离 VoiceSeparate
精彩集锦 VideoMontage
视频增强 VideoProcess
超级分辨率 SuperResolution
图片/文字水印 Watermark
语音合成 Tts
音视频转码 Pro TranscodePro
极速高清 HighSpeedHd
图片处理 PicProcess
语音识别 SpeechRecognition
视频目标检测 VideoTargetRec

具体的数据内容如下：

节点名称（关键字）父节点 描述 类型

Container 节点 Response 的内容：

节点名称（关键字）父节点 描述 类型
RequestId Response 请求的唯一 ID String
TotalCount Response 模板总数 Int
PageNumber Response 当前页数，同请求中的 pageNumber Int
PageSize Response 每页个数，同请求中的 pageSize Int
TemplateList Response 模板数组 Container 数组
