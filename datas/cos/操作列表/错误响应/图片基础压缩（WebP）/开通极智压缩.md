# 开通极智压缩

最近更新时间：2025-09-19 15:44:52


## 功能描述

开通当前存储桶的图片极智压缩功能。

## 授权说明

通过子账号使用时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加 `ci:SetImageSlim` 权限。数据万象支持的所有操作接口请参见 [CI action](https://cloud.tencent.com/document/product/598/98114)。

## 服务开通

使用该功能需提前 [绑定存储桶](https://cloud.tencent.com/document/product/460/46483)，开通数据万象服务。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

使用该接口时，请先确认相关限制条件。详情请参见 [使用限制](https://cloud.tencent.com/document/product/460/36620#Image-processing)。

## 费用说明

图片极智压缩为付费服务，产生的费用将由数据万象收取，详细计费说明可参见 [图片处理费用](https://cloud.tencent.com/document/product/460/58117)。

如果采用下载时处理的方式，且通过外网进行下载，调用会产生 [流量费用](https://cloud.tencent.com/document/product/460/58122)。

## 请求

#### 请求示例

PUT /?image-slim HTTP/1.1

Host: <BucketName-APPID>.pic.<Region>.myqcloud.com

Date: GMT Date

Authorization: Auth String

**说明：**

Authorization: Auth String，详情请参见 [请求签名](https://cloud.tencent.com/document/product/436/7778) 文档。

#### 请求头

#### 公共头部

该请求操作无特殊的请求头部信息，使用的公共请求头，请参阅 [公共请求头部](https://cloud.tencent.com/document/product/436/7728) 章节。

#### 请求体

<ImageSlim>

 <SlimMode>Auto</SimMode>

 <Suffixs>

 <Suffix>jpg</Suffix>

 <Suffix>png</Suffix>

 </Suffixs>

</ImageSlim>

节点名称 父节点 描述 类型 是否必填
ImageSlim 无 极智压缩配置信息 Container 是
SlimMode ImageSlim 极智压缩的使用模式，包含两种：

API：开通极智压缩的 API 使用方式，开通后可在图片下载时通过极智压缩参数对图片进行压缩

Auto：开通极智压缩的自动使用方式，开通后无需携带任何参数，存储桶内指定格式的图片将在访问时自动进行极智压缩

注意：支持同时开通两种模式，多个值通过逗号分隔 string 是
Suffixs ImageSlim 当 SlimMode 的值包含 Auto 时生效，用于指定需要自动进行压缩的图片格式 Container 否
Suffix Suffixs 需要自动进行压缩的图片格式，可选值：jpg、png、gif string 否，当 SlimMode 包含 Auto 时必填
