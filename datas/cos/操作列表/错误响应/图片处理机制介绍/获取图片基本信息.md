# 获取图片基本信息

最近更新时间：2025-09-19 15:44:52


## 功能概述

腾讯云数据万象通过 **imageInfo** 接口查询图片基本信息，包括格式、长、宽等。

## 授权说明

通过子账号使用时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加 `cos:GetObject` 权限。对象存储支持的所有操作接口请参见 [COS action](https://cloud.tencent.com/document/product/598/69901)。

**说明：**

GetObject 对应的 resource 为源文件。

## 服务开通

首次使用该功能时将默认为您开通数据万象，同时该存储桶将自动绑定数据万象，无需角色授权，即可直接使用。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

使用该接口时，请先确认相关限制条件。详情请参见 [使用限制](https://cloud.tencent.com/document/product/460/36620#Image-processing)。

## 费用说明

该接口将产生 [基础图片处理费用](https://cloud.tencent.com/document/product/460/58117)。

通过外网使用时，调用会产生 [流量费用](https://cloud.tencent.com/document/product/460/58122)，流量大小为返回的 json 响应体。

## 接口示例

GET /<ObjectKey>?imageInfo HTTP/1.1

Host: <BucketName-APPID>.cos.<Region>.myqcloud.com

Date: <GMT Date>

Authorization: <Auth String>

## 处理参数说明

#### 请求参数

参数 含义 类型 是否必填
ObjectKey 对象文件名，例如 folder/sample.jpg。String 是
imageInfo 该参数无其他值，为固定值，表示查询图片基本信息。String 是

#### 响应体

参数 含义 类型
format 图片类型，例如 png、gif 等，String
width 图片的宽度，单位为像素（px）。String
height 图片的高度，单位为像素（px）。String
size 图片的大小，单位为 Bytes。String
md5 图片的 md5 值。String
dynamic_range 图片是否为 hdr，有效值：hdr、gainmap hdr、sdr、unknow。String
frame_count 图片的帧数，静态图为1，动图为对应的帧数。String
bit_depth 图片的位深。String
vertical_dpi 图片的垂直分辨率。String
horizontal_dpi 图片的水平分辨率。String

## 实际案例

#### 案例一：公有读

#### 请求

http://examples-1251000004.cos.ap-shanghai.myqcloud.com/sample.jpeg?imageInfo

#### 响应

{"format": "jpeg", "width": "960", "height": "540", "size": "158421", "md5": "77a16fa70e2eba652fb42e8a639c52f2","dynamic_range": "unknow", "frame_count": "1", "bit_depth": "8", "vertical_dpi": "118", "horizontal_dpi": "118"}

#### 案例二：私有读、携带签名

获取方式同上，仅增加签名部分，并与获取参数以“&”连接，示例如下：

http://examples-1251000004.cos.ap-shanghai.myqcloud.com/sample.jpeg?q-sign-algorithm=<signature>&imageInfo

**说明：**

`<signature>`为签名部分，获取方式请参见 [请求签名](https://cloud.tencent.com/document/product/436/7778)。
