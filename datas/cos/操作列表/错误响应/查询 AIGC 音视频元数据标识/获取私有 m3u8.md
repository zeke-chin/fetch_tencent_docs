# 获取私有 m3u8

最近更新时间：2026-05-07 15:19:11


## 功能描述

GetPrivateM3U8接口用于获取私有的 m3u8 ts 资源的下载授权。（此方式通过对象存储转发请求至数据万象）。

## 授权说明

通过子账号使用该接口时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加 `ci:GetPrivateM3U8`。数据万象支持的所有操作接口请参见 [action](https://cloud.tencent.com/document/product/598/98114)。

## 服务开通

使用该功能需提前 [绑定存储桶](https://cloud.tencent.com/document/product/460/46483)，开通数据万象服务。

使用该功能需提前通过 [控制台](https://cloud.tencent.com/document/product/460/87745) 或 [接口](https://cloud.tencent.com/document/product/460/72823) 开通媒体处理服务。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

使用该接口时，请先确认相关限制条件。详情请参见 [使用限制](https://cloud.tencent.com/document/product/460/36620#Media-processing)。

## 费用说明

该接口为付费服务，产生的费用将由数据万象收取，详细计费说明可参见 [媒体处理费用](https://cloud.tencent.com/document/product/460/58120)。

## 请求

#### 请求示例

GET /<ObjectKey>?ci-process=pm3u8&expires=3600&StartTimeOffset=2&EndTimeOffset=10 HTTP/1.1

Host: <BucketName-APPID>.cos.<Region>.myqcloud.com

Date: <GMT Date>

Authorization: <Auth String>

Content-Length: <length>

**说明：**

Authorization: 携带鉴权信息，用于验证请求的合法性的请求头，请求参数必须签入签名信息中，详情请参见 [请求签名](https://cloud.tencent.com/document/product/436/7778) 文档。

#### 请求参数

参数的具体内容如下：

参数名称 描述 类型 是否必选
ObjectKey COS 存储桶中的文件名称。COS 存储桶由 Host 指定，例如在北京的 examplebucket-1250000000存储桶中的目录 test 下的文件 a.m3u8，则 Host 填写 examplebucket-1250000000.cos.ap-beijing.myqcloud.com，ObjectKey 填写 test/a.m3u8。String 是
ci-process 操作类型。固定值： pm3u8，代表使用获取私有 m3u8功能 String 是
expires 私有 ts 资源 url 下载凭证的相对有效期。单位为秒，范围为[3600，43200]。Int 是
StartTimeOffset 裁剪的开始偏移时间，单位秒。默认0，即从视频开头开始裁剪。负数表示距离视频结束多少秒开始裁剪。例如 -10表示从倒数第10秒开始裁剪。

示例值：2.1 Float 否
EndTimeOffset 裁剪的结束偏移时间，单位秒。默认0，即裁剪到视频尾部。负数表示距离视频结束多少秒结束裁剪。例如 -10表示到倒数第10秒结束裁剪。

示例值：10.1 Float 否
user-data 设置传递的自定义键值对，JSON 格式，例如：{"key1":"value1","key2":"value2"}，传递时需要使用 [base64 安全版本的 URL 编码](https://cloud.tencent.com/document/product/460/86595#1b54a43c-d985-441d-9c89-81ac6c4adc39)String 否

## 响应

#### 响应头

此接口仅返回公共响应头部，详情请参见 [公共响应头部](https://cloud.tencent.com/document/product/460/42866) 文档。

#### 响应体

该响应体为 m3u8 的内容，其中的 ts 为可下载的链接。

#### 错误码

该请求操作无特殊错误信息，常见的错误信息请参见 [错误码](https://cloud.tencent.com/document/product/460/42867) 文档。
