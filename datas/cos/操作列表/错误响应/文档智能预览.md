# 文档智能预览

最近更新时间：2025-08-29 15:03:52


## 功能描述

文档智能预览在传统文档 HTML 预览功能（支持 PPT、Word、Excel、PDF 等多种常见文档格式）的基础上，新增基于 DeepSeek 深度思考大模型的 AI 文档阅读助手，您可在预览文档时直接提问，例如“输出文档大纲”、“提取关键数据表格”等，AI 助手将快速帮助您分析文档。

**说明：**

文档智能预览限时开放体验，单击 [申请体验名额](https://cloud.tencent.com/apply/p/b5mnado682k)。

## 授权说明

通过子账号使用时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加 `ci:GenerateHtmlPreviewDocument` 权限。数据万象支持的所有操作接口请参见 [CI action](https://cloud.tencent.com/document/product/598/98114)。

## 服务开通

使用该功能需提前 [绑定存储桶](https://cloud.tencent.com/document/product/460/46483)，开通数据万象服务。

使用该功能需提前通过 [控制台](https://cloud.tencent.com/document/product/460/46499) 或 [接口](https://cloud.tencent.com/document/product/460/103608) 开通文档处理服务。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

文档预览部分限制与文档转 HTML 相同，详情请参见 [文档预览限制](https://cloud.tencent.com/document/product/460/36620#Document-processing)。

AI 助手问答限制如下：

支持的格式：pdf、pptx、docx、csv、xlsx。

支持进行 AI 分析的文档大小：50MB。

支持进行 AI 分析的文档字数限制：2万字。

AI 问答并发限制（QPS）：3。

地域限制：南京。

## 费用说明

文档智能预览的 AI 阅读助手当前处于内测阶段，不会产生费用。

预览区域将按照文档转 HTML 为付费功能，调用接口会产生 [文档转 HTML 费用](https://cloud.tencent.com/document/product/460/58121) 和 [流量费用](https://cloud.tencent.com/document/product/460/58122)，产生的费用将由数据万象收取。

## 请求

#### 请求示例

GET /<ObjectKey>?ci-process=doc-preview&dstType=html&AIModel=deepseek-r1 HTTP/1.1

Host: <BucketName-APPID>.cos.<Region>.myqcloud.com

Date: GMT Date

Authorization: Auth String

#### 请求头

此接口仅使用公共请求头部，详情请参见 [公共请求头部](https://cloud.tencent.com/document/product/460/42865) 文档。

#### 请求参数

名称 描述 类型 是否必选
ObjectKey 对象文件名，例如 folder/document.pdf String 是
ci-process 用于指定使用哪种数据万象处理能力，文档智能预览固定为：doc-preview String 是
dstType 输出目标文件类型，固定为 html（需为小写字母）String 是
AIModel 用于指定AI模型，当前仅支持：deepseek-r1 String 是

**注意：**

为了避免未授权人员通过访问不携带处理参数的链接实现访问和滥用 AI 阅读助手的情况，即使公有读的文档，您也必须携带签名进行访问，且需要将处理参数签入到请求签名中，处理参数整体是参数的 key，value 为空，详细计算方法请参见 [请求签名](https://cloud.tencent.com/document/product/436/14114)。

#### 请求体

该请求的请求体为空。
