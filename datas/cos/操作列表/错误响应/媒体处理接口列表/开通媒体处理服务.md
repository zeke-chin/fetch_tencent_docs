# 开通媒体处理服务

最近更新时间：2025-08-11 17:23:13


## 功能描述

本接口用于开通媒体处理服务并生成队列。

## 授权说明

通过子账号使用时，需要在 [授权策略](https://cloud.tencent.com/document/product/460/104297) 的 action 中添加 `ci:CreateMediaBucket` 权限。数据万象支持的所有操作接口请参见 [CI action](https://cloud.tencent.com/document/product/598/98114)。

## 服务开通

首次使用该功能时将默认为您开通数据万象，同时该存储桶将自动绑定数据万象，无需角色授权，即可直接使用。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 使用限制

使用该接口时，请先确认相关限制条件。详情请参见 [使用限制](https://cloud.tencent.com/document/product/460/36620#Media-processing)。

## 请求

#### 请求示例

POST /mediabucket HTTP/1.1

Host: <BucketName-APPID>.ci.<Region>.myqcloud.com

Date: <GMT Date>

Authorization: <Auth String>

Content-Length: <length>

Content-Type: application/xml

**说明：**

Authorization: Auth String，详情请参见 [请求签名](https://cloud.tencent.com/document/product/436/7778) 文档。

#### 请求头

此接口仅使用公共请求头部，详情请参见 [公共请求头部](https://cloud.tencent.com/document/product/460/42865) 文档。

#### 请求体

该请求的请求体为空。

## 响应

#### 响应头

此接口仅返回公共响应头部，详情请参见[公共响应头部](https://cloud.tencent.com/document/product/460/42866)文档。

#### 响应体

该响应体返回为 **application/xml** 数据，包含完整节点数据的内容展示如下：

<Response>

 <RequestId>NjJmNDczY2RfOTBmYTUwNjRfNTA4ZV85</RequestId>

 <MediaBucket>

 <BucketId>examplebucket-1250000000</BucketId>

 <Name>examplebucket-1250000000</Name>

 <Region>ap-beijing</Region>

 <CreateTime>2019-11-15T12:12:12+0800</CreateTime>

 <PlayKeyList>

 <MasterPlayKey>d93bfe5e82ae4995xxxxxxxxxxxxxxxx</MasterPlayKey>

 <BackupPlayKey>b47d30a0863a4884xxxxxxxxxxxxxxxx</BackupPlayKey>

 </PlayKeyList>

 </MediaBucket>

</Response>

具体的数据内容如下：

节点名称（关键字）父节点 描述 类型
Response 无 保存结果的容器 Container

Container 节点 Response 的内容：

节点名称（关键字）父节点 描述 类型
RequestId Response 请求的唯一 ID String
MediaBucket Response 媒体 Bucket 详情 Container

Container 节点 MediaBucket 的内容：

节点名称（关键字）父节点 描述 类型
BucketId Response.MediaBucket 存储桶 ID String
Name Response.MediaBucket 存储桶名称，同 BucketId String
Region Response.MediaBucket 所在的地域 String
CreateTime Response.MediaBucket 创建时间 String
PlayKeyList Response.MediaBucket 播放密钥列表 Container

Container 节点 PlayKeyList 的内容：

节点名称（关键字）父节点 描述 类型
MasterPlayKey Response.MediaBucket.PlayKeyList 主播放密钥 String
BackupPlayKey Response.MediaBucket.PlayKeyList 备播放密钥 String

#### 错误码

该请求无特有错误信息，常见的错误信息请参见 [错误码](https://cloud.tencent.com/document/product/460/42867) 文档。
