# 同步转码

最近更新时间：2025-08-11 17:23:13


## 功能描述

GetSyncConvert 接口用于获取媒体文件同步转码的结果，适用于 Live 实况图与 GIF 图处理以提升其兼容性。

## 使用说明

此接口为同步模式，异步模式请参见 [任务接口 > 转码任务](https://cloud.tencent.com/document/product/460/84790)。

## 服务开通

使用该功能需提前 [绑定存储桶](https://cloud.tencent.com/document/product/460/46483)，开通数据万象服务。

使用该功能需提前通过 [控制台](https://cloud.tencent.com/document/product/460/87745) 或 [接口](https://cloud.tencent.com/document/product/460/72823) 开通媒体处理服务。

**注意：**

数据万象绑定后，如果您手动对存储桶进行数据万象的解绑操作，将无法继续使用该功能。

## 限制说明

支持格式：目前该接口仅支持处理 Gif、Live 图格式的文件。

Gif 动图体积限制：处理图片原图大小不超过40MB，总像素不超过3亿像素。

Live 图体积限制：处理图片原图大小不超过20MB，总时长不超过4秒。

## 请求示例

#### 1. 通过 GET 请求方式

GET /<ObjectKey>?ci-process=convert&format=mp4 HTTP/1.1

Host: <BucketName-APPID>.cos.<Region>.myqcloud.com

Date: <GMT Date>

Authorization: <Auth String>

Content-Length: <length>

#### 2. 通过 URL 地址添加参数方式

https://<BucketName-APPID>.cos.<Region>.myqcloud.com/for-test.gif?ci-process=convert&format=mp4&<Auth String>

**说明：**

Authorization: Auth String（详情请参见 [请求签名](https://cloud.tencent.com/document/product/436/7778) 文档）。
