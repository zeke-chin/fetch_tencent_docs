# 开启自定义 CDN 加速域名

最近更新时间：2025-07-31 17:39:12


## 简介

本文仅介绍在对象存储（Cloud Object Storage，COS）控制台上添加自定义加速域名及开启 CDN 加速。若要在 CDN 控制台添加自定义域名，请参见 CDN [接入域名](https://cloud.tencent.com/document/product/228/41215) 文档。

## 操作步骤

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。 在左侧导航栏中，单击**存储桶列表**，进入存储桶列表页面。

2. 单击需要配置域名的存储桶，进入存储桶配置页面。

3. 选择**域名与传输管理**>**自定义 CDN 加速域名**，在**自定义 CDN 加速域名**区域，单击**添加域名**。

**说明：**

若您之前在老版本 COS 控制台使用过“自定义域名”，则在新版控制台不显示“自定义 CDN 加速域名”，仍显示“自定义域名”。

4. 在弹出的窗口中，配置如下信息。

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/3b670f4f3df31dbd8792bad4ac2b10e0.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/3b670f4f3df31dbd8792bad4ac2b10e0.png)

配置项说明如下：

**域名与 CNAME**：输入待绑定的自定义域名（例如 `www.example.com`）。请确保输入的域名已备案，并已在 DNS 服务商处设置好对应的 CNAME，详情请参见 [CNAME 配置](https://cloud.tencent.com/document/product/228/3121)。若您在接入的自定义 CDN 加速域名为以下情况，则需要进行域名归属权验证，详情请查看 [域名归属验证](https://cloud.tencent.com/document/product/228/61702)。

首次接入该域名

该域名已被其他用户接入

接入域名为泛域名

**加速地域**：支持中国境内、中国境外和全球加速，其中全球加速指支持所有地域之间的存储桶加速。

**源站类型**：支持默认源站、静态网站源站、全球加速源站。如果您的存储桶开启了静态网站功能或者全球加速功能，支持选择静态网站源站或者全球加速源站。

**回源鉴权**：对于私有读和公有读的存储桶，配置说明如下：

当存储桶为私有读，需要添加 CDN 服务授权并且开启回源鉴权。否则，CDN 边缘节点访问 COS 源站中的数据，将被拒绝访问。

**说明：**

若开启 CDN 服务授权和回源鉴权，CDN 访问 COS 源站时无需携带签名，且 CDN 缓存资源将进行公网分发，数据的安全性可能会受到影响。**因此，强烈建议同时开启 CDN 鉴权和回源鉴权，保障数据安全**。

CDN 鉴权用于开启时间戳鉴权配置，可防止恶意用户盗取内容，可在添加完域名后进行设置。

当存储桶为公有读时，无需开启回源鉴权。

5. 配置完成后，单击**创建，**即可在列表页看到已配置的自定义 CDN 域名。

![Image 4](https://qcloudimg.tencent-cloud.cn/image/document/3250b5e017e57249b91bebf77c92f72b.png)

![Image 5](https://qcloudimg.tencent-cloud.cn/image/document/3250b5e017e57249b91bebf77c92f72b.png)

列表项说明如下：

**基本信息**：展示域名、CNAME、加速地域、源站类型的配置信息。

**鉴权**：展示回源鉴权、CDN 鉴权的配置状态。

**注意：**

如果是私密数据，请务必配置 **CDN 鉴权**来保护您的源站数据。支持以下两种方式进行配置：

**COS 控制台快捷跳转配置**：点击 CDN 鉴权的气泡，根据提示单击“CDN 控制台”，快捷跳转至 CDN 控制台进行配置。

**CDN 控制台直接配置**：在 CDN 控制台选择需要配置的域名，详情请参见 [鉴权配置说明](https://cloud.tencent.com/document/product/228/41622)。

**HTTPS 证书**：展示 HTTPS 证书的配置状态。

未配置：当前域名未配置证书。如需配置，可点击气泡，根据提示单击“CDN 控制台”，快捷跳转至 CDN 控制台进行配置。证书绑定后，预计30分钟内生效。操作指引请参见 [HTTPS 配置指南](https://cloud.tencent.com/document/product/228/41687)。

已配置：当前域名已配置证书，支持展示证书的到期时间。

**个性化配置**：展示 CDN 智能压缩、CDN 缓存自动刷新、图片自适应压缩的配置信息。具体说明如下：

**CDN 智能压缩**：展示 CDN 智能压缩的配置状态或已配置的压缩方式。

（1）添加域名后，默认会为该域名创建并开启一条 Gzip 智能压缩规则。

若显示“未配置”，指未开启 CDN 智能压缩配置状态。

若显示“gzip”或其他字段，指当前配置的压缩方式。

（2）为了减少传输文件大小，节省开销，推荐开启 CDN 智能压缩。可点击气泡，根据提示单击“CDN 控制台”，快捷跳转至 CDN 控制台进行配置。操作指引请参见 [智能压缩配置](https://cloud.tencent.com/document/product/228/41736)。

**说明：**

默认 Gzip 智能压缩规则，即对后缀 .js、.html、.css、.xml、.json、.shtml、.htm，大小为256Byte - 2MB范围内的资源开启 Gzip 压缩。有关 Gzip 压缩的更多信息，请参见 [配置自定义 CDN 域名支持 Gzip 压缩](https://cloud.tencent.com/document/product/436/101601)。

**CDN 缓存自动刷新**：展示 CDN 缓存自动刷新的配置状态。

开启后，触发 COS 存储桶更新文件规则时，将自动刷新 CDN 缓存。如需配置该功能，可点击气泡，根据提示单击“函数计算”，快捷跳转至 COS 函数计算进行配置。操作指引请参见 [设置 CDN 缓存刷新](https://cloud.tencent.com/document/product/436/45597)。

**图片自适应压缩：**展示图片自适应压缩的配置状态。

当您通过绑定域名分发图片时，若浏览器支持预览压缩格式的图片，后台将实时压缩，分发压缩后的图片。如需配置该功能，可点击气泡，根据提示单击**修改配置**，支持一键开启自适应压缩。

**状态：**展示当前域名的上线状态。

添加域名后，会对域名进行部署，部署成功后会显示已上线。如需下线域名，单击**操作**列的**编辑 ，**将**状态**修改为“下线”，保存即可。

**操作：**支持编辑和删除。

**注意：**

不支持删除已上线的域名。如需删除某条域名，请先修改该域名的状态为下线状态。
