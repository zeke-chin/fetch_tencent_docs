# 设置回收站

最近更新时间：2025-07-31 15:50:41


# 简介

您可以通过对象存储控制台，为您的存储桶开启回收站功能。回收站功能为存储桶中的对象提供一个临时存储站点，用于保留被误删的数据。开启该功能后，所有被删除的文件不会被永久删除，而是被存放至回收站，用户可以对这些文件进行恢复和管理，这不仅有效降低了数据丢失的风险，也提升了数据管理的效率。

**说明：**

回收站列表目前会列出所有文件的历史版本和删除标记（Delete Marker），您可以按需进行操作，关于历史版本和删除标记的有关说明请参见 [版本控制概述](https://cloud.tencent.com/document/product/436/19883) 和 [删除标记](https://cloud.tencent.com/document/product/436/45336)。

回收站内的文件仍然会产生存储容量费用，删除标记不会被计费，详情请参见 [存储容量费用](https://cloud.tencent.com/document/product/436/53482)；删除回收站内的文件会产生请求费用，详情请参见[请求费用](https://cloud.tencent.com/document/product/436/53861)；低频、归档和深度归档存储类型的数据，有最短存储时长限制；分别是30天、90天、180天，若存在提前删除，则按照对应存储类型的最短存储时长计费。详情见 [关于提前删除的说明](https://cloud.tencent.com/document/product/436/53482#.E5.85.B3.E4.BA.8E.E6.8F.90.E5.89.8D.E5.88.A0.E9.99.A4.E7.9A.84.E8.AF.B4.E6.98.8E)。

# 注意事项

回收站功能依赖于版本控制，开启回收站后将同步开启版本控制，关于版本控制的说明请参见 [版本控制概述](https://cloud.tencent.com/document/product/436/19883) 和 [设置版本控制](https://cloud.tencent.com/document/product/436/19881)。

如需进行大批量文件操作，推荐您 [设置生命周期](https://cloud.tencent.com/document/product/436/14605) 进行操作。

数据被彻底删除后不可恢复和访问，请谨慎操作。

当对象的最新版本为删除标记时，执行删除操作将还原对象为上一个历史版本，请谨慎操作。

# 操作步骤

## 开启回收站

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。

2. 在左侧导航栏中，单击**存储桶列表**，进入存储桶列表页面。

3. 单击需要开启回收站的存储桶，进入存储桶详情页面。

4. 在左侧导航栏中，选择**回收站列表**，单击**开启回收站。**

5. 确认信息后，单击**确定**，即可开启存储桶的回收站功能，版本控制功能也会被同步开启。

## 还原历史版本

#### 还原单个历史版本

1. 在回收站列表找到需要还原的历史版本文件。

2. 在操作栏单击**还原，**进入信息确认弹窗**。**

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/9ed18be3d9f6ee1afffe9831a10cf138.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/9ed18be3d9f6ee1afffe9831a10cf138.png)

3. 在该弹窗内，您可以按需选择还原后是否删除原历史版本文件。

4. 确认信息无误后，单击**确定**，该历史版本将被还原，成为最新版本。

#### 批量还原历史版本

1. 在回收站列表选中需要批量还原的历史版本文件。

2. 在列表页单击**批量还原，**进入信息确认弹窗**。**

![Image 4](https://qcloudimg.tencent-cloud.cn/image/document/f87af3a6b6058e1a848515f4a788bd4c.png)

![Image 5](https://qcloudimg.tencent-cloud.cn/image/document/f87af3a6b6058e1a848515f4a788bd4c.png)

3. 确认信息无误后，单击**确定**，即可批量还原历史版本。

## 清空历史版本

1. 在回收站列表单击**清空历史版本，**进入信息确认弹窗。

![Image 6](https://qcloudimg.tencent-cloud.cn/image/document/a536026aecbfce4a3acff53abde407f8.png)

![Image 7](https://qcloudimg.tencent-cloud.cn/image/document/a536026aecbfce4a3acff53abde407f8.png)

2. 确认信息无误后，按照提示输入**存储桶名称**，单击**确定清空**，即可清空回收站内所有文件夹、对象的历史版本。

**注意：**

清空后，历史版本将被彻底删除，不可恢复和访问，请谨慎操作。

## 开启历史版本定期清理

对象存储支持定期清理回收站内的历史版本和无历史版本的删除标记，您可以在回收站开启历史版本定期清理功能，开启后，将自动为您配置一条定期清理的生命周期规则，更多自定义规则，请您前往 [设置生命周期](https://cloud.tencent.com/document/product/436/14605)。在回收站开启历史版本定期清理规则的操作步骤如下。

1. 在回收站列表**右侧**找到历史版本定期清理的开关。

![Image 8](https://qcloudimg.tencent-cloud.cn/image/document/1472100b92e486f3771ece3f6403bb2b.png)

![Image 9](https://qcloudimg.tencent-cloud.cn/image/document/1472100b92e486f3771ece3f6403bb2b.png)

2. **打开开关，**进入配置弹窗。您可以按需配置历史版本文件需要被自动删除的天数，更多字段说明请参见 [设置生命周期](https://cloud.tencent.com/document/product/436/14605)。

**说明：**

若您此前已配置生命周期历史版本删除规则，开启历史版本定期清理后将以 [规则执行优先级](https://cloud.tencent.com/document/product/436/14605#75d222df-3fe9-4f1c-8892-49a43b8e38c8) 执行删除，请按需配置。

![Image 10](https://qcloudimg.tencent-cloud.cn/image/document/750e61e25cfb40d2c0613b7ae8a13b9f.png)

![Image 11](https://qcloudimg.tencent-cloud.cn/image/document/750e61e25cfb40d2c0613b7ae8a13b9f.png)

3. 信息确认无误后，单击**确定**，即可开启历史版本定期清理，在指定的配置天数后，历史版本将会被自动删除。

**注意：**

删除后数据不可恢复和访问，请谨慎操作。

4. 开启后支持查看该规则详情，将鼠标悬浮于“历史版本定期清理”文字上，即可进行查看。

![Image 12](https://qcloudimg.tencent-cloud.cn/image/document/424bce9dfd3b1f8314f3d10c72ced39c.png)

![Image 13](https://qcloudimg.tencent-cloud.cn/image/document/424bce9dfd3b1f8314f3d10c72ced39c.png)

5. 若您需要更改历史版本定期清理规则，将鼠标悬浮于“历史版本定期清理”文字上，单击**编辑**，按需配置即可。

## 关闭历史版本定期清理

1. 在回收站列表**右侧**找到历史版本定期清理的开关。

2. **关闭开关**，进入确认弹窗，确认无误后单击**确定**，即可关闭历史版本定期清理，同时该生命周期规则将会被同步删除。
