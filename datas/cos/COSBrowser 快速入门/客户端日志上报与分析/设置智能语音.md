# 设置智能语音

最近更新时间：2025-08-29 15:03:52


## 简介

智能语音服务可以对已经录制完成的录音文件，进行识别，降噪、词性分析等处理，也可以对文字进行语音合成。

## 注意事项

支持中文普通话、英语和粤语的语音识别、语音合成。

语音识别语音文件的时长不能大于5小时，文件大小不超过512MB。

智能语音是付费服务，由数据万象计费，按照时长进行计费，详细的计费说明请参见数据万象 [智能语音费用](https://cloud.tencent.com/document/product/460/81777)。

## 操作步骤

您可通过控制台开启服务，开启服务后，对于当前存储桶中的音频资源，使用相应的 [智能语音](https://cloud.tencent.com/document/product/460/81072) API 接口即可创建智能语音相关任务。

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos)。

2. 在左侧导航栏中，单击**存储桶列表**，进入存储桶列表管理页面。

3. 找到需要操作的存储桶，单击该**存储桶名称**，进入该存储桶管理页面。

4. 在左侧导航栏中，单击**数据处理**>**智能语音**，进入智能语音管理页面。

5. 在**智能语音**配置项中，单击**编辑**，将状态修改为**开启**。

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/3cd9670f039d7fbab414ff92019aed08.png)

6. 开启服务后，系统会自动创建一个数据万象智能语音任务队列。当用户 [提交智能语音任务](https://cloud.tencent.com/document/product/436/53968#.E5.88.9B.E5.BB.BA.E6.99.BA.E8.83.BD.E8.AF.AD.E9.9F.B3.E4.BB.BB.E5.8A.A1) 后，任务会先进入队列中进行排列，系统将根据优先级和提交顺序依次执行。

![Image 4](https://qcloudimg.tencent-cloud.cn/image/document/7324dc98b54f978b46f6346571bf3f05.png)

![Image 5](https://qcloudimg.tencent-cloud.cn/image/document/7324dc98b54f978b46f6346571bf3f05.png)

7. 队列创建完毕后，可以设置回调规则，及时了解任务或工作流进度，同时系统会将处理结果状态提交到您的指定地址。

8. 单击队列操作栏中的**回调规则**。

9. 在弹出的窗口中，修改当前状态，即可开启或关闭回调。开启回调需设置指定 URL，用于系统发送 HTTP 请求。回调详情请查看回调内容。

![Image 6](https://qcloudimg.tencent-cloud.cn/image/document/75b59635b041648b3809f6a0aac2d5ea.png)

![Image 7](https://qcloudimg.tencent-cloud.cn/image/document/75b59635b041648b3809f6a0aac2d5ea.png)

#### 回调内容

任务完成后，系统会向您设置的回调地址发送回调内容，内容展示如下：

<Response>

 <JobsDetail></JobsDetail>

 <NonExistJobIds></NonExistJobIds>

</Response>

参数说明如下：

参数 描述 类型
JobsDetail 任务的详细信息，同 CreateMediaJobs 接口的 [Response.JobsDetail](https://cloud.tencent.com/document/product/436/85080) 节点 Container
NonExistJobIds 查询的 ID 中不存在的任务，所有任务都存在时不返回 String
