# 设置文档预览

最近更新时间：2025-08-29 15:03:52


## 简介

本篇文档说明了如何开通文档预览功能，开通后您可以使用**文档转图片**、**文档转 HTML**以及**文档智能预览**三种方式对存储在 COS 中的文档进行预览。关于文档预览的相关说明，请参见 [文档处理](https://cloud.tencent.com/document/product/436/45906)。

**注意：**

文档预览功能支持的地域：中国大陆公有云以及硅谷、弗吉尼亚、法兰克福、新加坡，其中新加坡和硅谷地域目前仅支持文档转图片预览。

文档预览功能为收费项，由数据万象收取，具体费用请参见 [计费与定价](https://cloud.tencent.com/document/product/460/6970)。

数据万象在每个账户在首次产生**文档预览转图片**用量后，将发放一个用量为6000页，有效期为2个月的文档预览转图片免费额度资源包，超出用量或资源包到期后将正常计费。

文档智能预览限时开放体验中，目前仅支持南京地域，在开通文档预览功能后，还需 [申请体验名额](https://cloud.tencent.com/apply/p/b5mnado682k) 才能进行使用。

## 操作步骤

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。

2. 在左侧导航中，单击**存储桶列表**，单击需要开启文档预览功能的存储桶，进入存储桶管理页。

3. 选择**数据处理**>**文档处理**，在**文档预览**配置项中，单击**编辑**，将**状态**修改为开启。

4. 单击**保存**，即可开启文档预览服务。

5. 开启文档预览服务后，回到**文件列表**，选中想要预览的文件。

**说明：**

目前支持预览的文件类型包含如下格式：

演示文件：pptx、ppt、pot、potx、pps、ppsx、dps、dpt、pptm、potm、ppsm。

文字文件：doc、dot、wps、wpt、docx、dotx、docm、dotm。

表格文件：xls、xlt、et、ett、xlsx、xltx、csv、xlsb、xlsm、xltm、ets。

其他格式文件： pdf、 lrc、 c、 cpp、 h、 asm、 s、 java、 asp、 bat、 bas、 prg、 cmd、 rtf、 txt、 log、 xml、 htm、 html。

文件大小限制在200MB之内，文件页数限制在5000页之内。

演示、文字、表格文件全部支持**复制预览链接。**其他格式文件中，仅 pdf、rtf、lrc、bat、bas、prg、cmd 格式文件支持**复制预览链接**。

在控制台进行 html 普通预览。

列表视图单击右侧操作列中**预览**按钮，图标视图单击右上角**三个点**选择**预览**选项，即可在线预览该文档。

## 其它预览方式

在开启文档预览服务后，除上述方式，您还可以通过以下两种方式预览文档：

### 方式一：创建文档预览任务

您可以在控制台进行文档异步转码预览的操作，详情请参见 [创建文档预览任务](https://cloud.tencent.com/document/product/436/53968#.E5.88.9B.E5.BB.BA.E6.96.87.E6.A1.A3.E9.A2.84.E8.A7.88.E4.BB.BB.E5.8A.A1) 控制台指南文档。

### 方式二：使用 REST API 同步转码

您可以使用 API 对文档进行实时转码预览：

使用非 HTML5预览，详情请参见 [同步请求接口](https://cloud.tencent.com/document/product/436/54058) API 文档。

使用 HTML5预览，详情请参见 [文档转 HTML 同步请求](https://cloud.tencent.com/document/product/436/54059) API 文档。

使用智能预览，详情请参见 [文档智能预览](https://cloud.tencent.com/document/product/436/116879) API 文档。
