# 删除存储桶

最近更新时间：2025-11-05 17:27:02


## 前提条件

在开始执行删除存储桶前，请您确认已满足以下条件：

已完成存储桶内所有文件及其历史版本的删除。如何删除文件及其历史版本，请参见 [清空存储桶](https://cloud.tencent.com/document/product/436/35247) 。

已完成存储桶内所有文件的碎片文件的删除。如何删除碎片文件，请参见 [删除碎片](https://cloud.tencent.com/document/product/436/17313)。

已关闭 CDN 加速域名、自定义 CDN 加速域名。如需关闭，请参见 [CDN 加速配置](https://cloud.tencent.com/document/product/436/18670#.E6.93.8D.E4.BD.9C.E6.AD.A5.E9.AA.A4)。

已确认具有删除存储桶的操作权限。

主账号默认拥有删除存储桶的权限。如果您的账号是子账号，可以选择以下方案获取删除存储桶的权限：

**方案一：**[添加收藏路径](https://cloud.tencent.com/document/product/436/17061#.E6.B7.BB.E5.8A.A0.E8.AE.BF.E9.97.AE.E8.B7.AF.E5.BE.84)：使用主账号授予子账号特定存储桶的用户权限，并在子账号登录对象存储控制台后，添加存储桶的收藏路径，即可实现删除存储桶的操作权限。

**方案二：**[添加预设策略](https://cloud.tencent.com/document/product/436/17061#.E6.B7.BB.E5.8A.A0.E9.A2.84.E8.AE.BE.E7.AD.96.E7.95.A5)：为子账号添加预设策略 QcloudCOSFullAccess 或 QcloudCOSDeleteBucketAccess（删除指定存储桶的权限）来访问存储桶，并实现删除存储桶的操作。

## 注意事项

**请您务必仔细阅读以下信息，忽略该信息可能对您的业务造成影响。**

删除存储桶时，您需要确保操作的身份已被授权该操作，并确认传入了正确的存储桶名称（Bucket）和地域（Region）参数。

删除存储桶后，数据无法恢复，请在删除前确认数据已不再使用。如果需要继续使用存储桶中的数据，请参见 [云上数据备份](https://cloud.tencent.com/document/product/436/39189) 提前做好备份。

删除存储桶后，需要等待数小时（通常为4到8个小时）才能重名创建。在此期间，该名称对所有人开放，可用于新建存储桶。若希望继续使用原存储桶名称，建议清空内容而非直接删除，以便保留存储桶。

## 使用方法

### 使用对象存储控制台

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)，在左侧导航栏中单击**存储桶列表**，进入存储桶列表页。

2. 找到您需要删除的存储桶，在其右侧操作栏下，单击**更多**>**删除**。

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/5a896b9efa06f50b1f00ddbbef84c294.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/5a896b9efa06f50b1f00ddbbef84c294.png)

3. 在弹出的对话框中，根据系统检测结果进行操作即可删除存储桶。

### 使用 REST API/SDK

您可以直接使用 REST API 发起删除存储桶请求，详情请参见 [DELETE Bucket](https://cloud.tencent.com/document/product/436/7732) API 文档。

您可以直接调用 SDK 的删除存储桶方法，详情请参见下列各语言 SDK 文档：

[Android](https://cloud.tencent.com/document/product/436/34535#.E5.88.A0.E9.99.A4.E5.AD.98.E5.82.A8.E6.A1.B6)、[C](https://cloud.tencent.com/document/product/436/35557#.E5.88.A0.E9.99.A4.E5.AD.98.E5.82.A8.E6.A1.B6)、[C++](https://cloud.tencent.com/document/product/436/113841)、[.NET](https://cloud.tencent.com/document/product/436/63392)、[Flutter](https://cloud.tencent.com/document/product/436/86282#.E5.88.A0.E9.99.A4.E5.AD.98.E5.82.A8.E6.A1.B6)、[Go](https://cloud.tencent.com/document/product/436/65640)、[iOS](https://cloud.tencent.com/document/product/436/34106#.E5.88.A0.E9.99.A4.E5.AD.98.E5.82.A8.E6.A1.B6)、[Java](https://cloud.tencent.com/document/product/436/35214)、[JavaScript](https://cloud.tencent.com/document/product/436/35648)、[Node.js](https://cloud.tencent.com/document/product/436/36118#.E5.88.A0.E9.99.A4.E5.AD.98.E5.82.A8.E6.A1.B6)、[PHP](https://cloud.tencent.com/document/product/436/64277)、[Python](https://cloud.tencent.com/document/product/436/35150#.E5.88.A0.E9.99.A4.E5.AD.98.E5.82.A8.E6.A1.B6)、[React Native](https://cloud.tencent.com/document/product/436/86697#.E5.88.A0.E9.99.A4.E5.AD.98.E5.82.A8.E6.A1.B6)、[小程序](https://cloud.tencent.com/document/product/436/36159#.E5.88.A0.E9.99.A4.E5.AD.98.E5.82.A8.E6.A1.B6)。
