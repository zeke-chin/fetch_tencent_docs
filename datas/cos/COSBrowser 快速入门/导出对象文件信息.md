# 导出对象文件信息

最近更新时间：2025-07-31 15:50:41


## 简介

您可以通过对象存储控制台，自定义导出存储桶中的对象信息（包括已上传的对象、文件夹下的对象），包括**文件名、文件URL、文件大小、存储类型、修改时间**等。支持批量导出对象地址列表操作，详情请查看操作步骤。

**说明：**

批量导出文件信息，支持最多导出10000个文件。如需导出更多，请通过 API 或 SDK 导出。详情请参见 [GET Bucket（List Objects）](https://cloud.tencent.com/document/product/436/7734)。

## 操作步骤

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。

2. 在左侧导航栏中，单击**存储桶列表**，进入存储桶列表页面。

3. 找到对象所在的存储桶，单击其存储桶名称，进入存储桶管理页面。

4. 在左侧导航栏中，选择**文件列表**，进入文件列表页面。

5. 勾选需要导出文件信息的对象，单击上方的**更多操作**>**导出文件信息**。

6. 在弹出的提示窗口中，配置如下信息：

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/a1e81b8d6f02037faf3cd55e8863ae6c.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/a1e81b8d6f02037faf3cd55e8863ae6c.png)

**导出字段**：支持导出多种字段。默认勾选文件名、文件URL。文件大小、存储类型、修改时间可选。

**传输协议**：默认选择 HTTPS 协议。支持 HTTPS 协议、HTTP 协议两种，您可根据需求选择。 **指定域名**：支持默认源站域名。

**过期时间**：默认过期时间为60分钟。支持自定义过期时间，输入5 - 60之间的整数即可。

7. 单击**确认**，即可导出对象文件信息。在导出文件中查看文件信息导出详情。

**注意：**

因导出配置中已设置过期时间，请在有效期内查看对象文件信息。
