# 存储桶复制配置

最近更新时间：2025-08-04 17:57:32


## 适用场景

通过配置存储桶复制规则，用户可以将对象数据从源存储桶复制到另一指定的目标存储桶中。存储桶复制功能适用于异地容灾、满足行业合规性要求、数据迁移与备份、降低客户访问延迟、方便不同地域的集群访问数据等场景。

特殊场景：

多地域备份：支持针对源存储桶配置多条复制规则，复制对象到不同地域的存储桶，实现多地域备份容灾。

双向复制：支持通过在源存储桶和目标存储桶中分别创建复制规则，实现两个存储桶的双向复制，实现存储桶数据的同步。

**注意：**

开启了版本控制后，新上传的同名对象将会产生历史版本并占用存储空间，因此这些版本的对象同样收取存储费用。

## 使用方法

### 使用对象存储控制台

#### 启用存储桶复制

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。

2. 在左侧导航栏，单击**存储桶列表**。

3. 单击需要配置存储桶复制的源存储桶，进入存储桶详情页面。

4. 选择左侧的**容错容灾管理**>**存储桶复制**，进入当前页面。

5. 在**存储桶复制**区域单击**新增规则**，配置项说明如下：

**基础信息**

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/19f89affc297b0534d3e2f63ebd37684.png)

![Image 3](https://qcloudimg.tencent-cloud.cn/image/document/19f89affc297b0534d3e2f63ebd37684.png)

**状态**：当前规则的状态。

**源地域**：您的源存储桶所属地域。

**应用范围**：指需要复制的源存储桶中的对象范围，支持选择整个存储桶或指定范围。

**整个存储桶**：指将源存储桶的所有增量对象复制到目标存储桶。

**指定范围**：指按照对象前缀、对象标签筛选待复制的增量对象。当您选择**指定范围**时，请至少配置以下其中一项：

**对象前缀**：可指定具有相同 [对象键](https://cloud.tencent.com/document/product/436/13324#.E5.AF.B9.E8.B1.A1.E9.94.AE) 前缀的对象去执行存储桶复制规则，例如 `prefix/`。不支持正则表达式。

**对象标签**：可指定带有同一标签的对象去执行存储桶复制规则，最多支持指定10个标签，请区分英文字母大小写。

**注意：**

可同时指定对象前缀和对象标签。对象前缀和对象标签、对象标签和对象标签之间都为“与”的关系（即所有条件需同时满足）。例如在存储桶复制规则中指定对象前缀为 doc，对象标签键值对为 `group = IT`，则指定的对象范围为当前存储桶中对象键前缀为 doc 且对象标签为group = IT 的所有增量对象。

**规则配置**

![Image 4](https://qcloudimg.tencent-cloud.cn/image/document/b882be8f9ca81ec06411d560fb08dda6.png)

![Image 5](https://qcloudimg.tencent-cloud.cn/image/document/b882be8f9ca81ec06411d560fb08dda6.png)

**目标存储桶**：指对象被复制后所存放的存储桶，可选择与源存储桶同地域或不同地域的存储桶，不支持选择非当前账号的存储桶。设定后，此后再新增多条存储桶复制规则时，相同的目标地域仅允许设置此前已指定过的目标存储桶。

**说明：**

如果源存储桶和目标存储桶均未开启版本控制功能，请先开启版本控制功能后，再配置存储桶复制规则。

假设规则 1 中指定了目标存储桶为南京的存储桶 A。如果再新增一条规则 2，指定目标存储桶为南京的存储桶，则只能选择存储桶 A，否则会报错。

**目标存储类型**：指对象被复制到目标存储桶后的存储类型。支持选择不同存储类型以改变目标存储桶中被复制对象的类型。有些存储类型仅适用于部分地域，关于存储类型的介绍和适用地域说明，请参见 [存储类型概述](https://cloud.tencent.com/document/product/436/33417)。

**同步删除标记**：支持选择同步或者不同步，默认为不同步。

**同步**：若选择同步删除标记， 则存储桶复制会将该标记复制到目标存储桶，**请谨慎选择**。当源桶文件被删除时，存储桶复制行为如下：

**不指定版本 ID 删除文件时**，COS 将在源存储桶中添加删除标记，存储桶复制会将该标记复制到目标存储桶，目标桶文件也将同步被删除。

**指定版本 ID 删除文件时**，COS 将删除源存储桶中指定的对象版本，但不会在目标存储桶中复制这一删除操作，即 COS 不会在目标存储桶中删除指定的对象版本。此行为可防止恶意删除数据。

**不同步**：若选择不同步删除标记，则目标存储桶不会新增删除标记。当源桶文件被删除时，存储桶复制不会将删除标记复制到目标存储桶，目标桶文件不受影响。

两种情况下，目标存储桶均不会实际删除对应文件，用户仍可通过指定版本 ID 访问对象历史版本。关于版本控制和删除标记的详细信息请参见 [版本控制概述](https://cloud.tencent.com/document/product/436/19883) 文档。

**说明：**

**生命周期产生的删除标记、沉降操作等不会同步到目标桶。**如果您希望目标存储桶能够删除过期对象，需要您单独对目标存储桶配置与源存储桶相同的生命周期规则。详情请参见 [存储桶复制概述](https://cloud.tencent.com/document/product/436/19237) 和 [复制行为说明](https://cloud.tencent.com/document/product/436/19923)。

当**应用范围**选择指定范围，且**选择范围**是对象标签时，在**规则配置页面**无法选择同步删除标记。

**规则优先级**：当前存储桶复制规则的优先级。系统会按照默认逻辑为每条规则分配优先级，如需修改，请在规则列表页单击**调整优先级**进行操作。操作详情请参见 [调整规则优先级](https://cloud.tencent.com/document/product/436/19235#d0d19637-8e21-49f3-9972-7e8f89afb25b)。

6. 信息确认无误并勾选授权后，单击**确定**，您即可看到存储桶复制规则。

![Image 7](https://qcloudimg.tencent-cloud.cn/image/document/fd91db7fc28412d8c054f33e52695838.png)

**注意：**

当您完成配置规则后，可对规则进行管理操作。您可单击编辑按钮修改当前规则及状态，单击删除按钮可删除当前规则。

#### 调整存储桶复制规则优先级

**注意：**

优先级支持1-1000，数字越小，优先级越大。

不同规则的优先级不能重复。

若您在功能升级之前已配置过“存储桶复制规则”，该部分规则暂无优先级，展示为“-”。详情如下：

如果您后续新增/编辑规则，则会按照默认逻辑为您之前的已配置规则分配优先级，将旧规则统一转换为带优先级字段的新规则，您可根据业务需求对优先级进行调整。

如果您后续未新增/编辑规则，仍会按您之前的规则进行存储桶复制。

您可以通过以下方式调整存储桶复制规则的优先级。操作步骤如下：

![Image 8](https://qcloudimg.tencent-cloud.cn/image/document/726773040cf5ea9b709f4a104db0f950.png)

![Image 9](https://qcloudimg.tencent-cloud.cn/image/document/726773040cf5ea9b709f4a104db0f950.png)

1. 在**存储桶复制**的规则列表页，单击**调整优先级**。

2. 通过加减按钮或者输入您预期的优先级。

3. 单击**确定**，完成存储桶复制规则的优先级调整。

#### 关闭存储桶复制

**注意：**

尚未完成的存储桶复制操作，将在关闭存储桶复制时中止，并将无法继续执行。

对存储桶再次启用存储桶复制时，仅对开启完成后新增的对象执行存储桶复制操作。

您可通过两种方式关闭存储桶复制功能：通过编辑规则和删除规则。

![Image 10](https://qcloudimg.tencent-cloud.cn/image/document/998cf373ac783f186448e99a5f19d84d.png)

![Image 11](https://qcloudimg.tencent-cloud.cn/image/document/998cf373ac783f186448e99a5f19d84d.png)

**编辑规则**：在**存储桶复制**管理项里编辑已添加的规则，通过规则中的状态按钮暂时禁用当前规则，这一操作将暂停当前存储桶复制功能，已复制数据将被保留在目标存储桶中，源存储桶中的增量数据将不再复制到目标存储桶，如需再次使用，单击**开启**按钮即可。

**删除规则**：在**存储桶复制**管理项里删除已添加的规则，删除规则后已配置的存储桶复制规则将失效，已复制数据将被保留在目标存储桶中，源存储桶中的增量数据将不再进行存储桶复制操作，如需再次使用，您需要重新添加规则。
