# 直传归档

最近更新时间：2025-09-15 16:11:22


## 简介

目前对象存储（Cloud Object Storage，COS）支持直传归档，您可直接将对象设置为归档类型并上传到 COS，直传归档的方式包括控制台、API、SDK、COSCMD 工具。此外您还可以通过 COS 的生命周期功能将已上传的对象沉降为归档类型。关于归档类型（例如归档存储、深度归档存储等）的详细介绍，请参见 [存储类型概述](https://cloud.tencent.com/document/product/436/33417)。

## 直传归档的方式

### 控制台上传

[COS 控制台](https://console.cloud.tencent.com/cos5) 的**上传文件**，选择上传对象后，在设置对象属性中将存储类型选择为归档类型（例如归档存储、深度归档存储等），详情请参见 [上传对象](https://cloud.tencent.com/document/product/436/13321)。

### API 上传

通过在 [PUT Object](https://cloud.tencent.com/document/product/436/7749)、[POST Object](https://cloud.tencent.com/document/product/436/14690) 或 [Initiate Multipart Upload](https://cloud.tencent.com/document/product/436/7746) 中将 x-cos-storage-class 设置为 ARCHIVE、MAZ_ARCHIVE 或 DEEP_ARCHIVE，实现直传归档。

### SDK 上传

当前 COS 发布 [所有 SDK](https://cloud.tencent.com/document/product/436/6474) 都支持直传归档，具体方式为在文件上传时，将 StorageClass 参数设置为 ARCHIVE、MAZ_ARCHIVE 或 DEEP_ARCHIVE，实现直传归档。

### COSCMD 工具上传

[COSCMD 工具](https://cloud.tencent.com/document/product/436/10976) 支持直传归档，具体方式为在文件上传时，通过增加头部字段 x-cos-storage-class，并设置为 ARCHIVE、MAZ_ARCHIVE 或 DEEP_ARCHIVE，实现直传归档。

## 归档恢复与下载

与标准存储/低频存储不同，归档类型（例如归档存储、深度归档存储等）的对象在下载前，需要先执行恢复操作（解冻），恢复完成后方可下载。恢复操作有如下三种方式：

快速取回模式：时间最短，通常只需要1到5分钟完成数据取回。

标准取回模式：使用标准取回模式，一般可在3到5小时完成数据取回。

批量取回模式：成本最低，一般在5到12小时可完成数据取回。

**说明：**

深度归档存储类型的文件不支持使用快速取回模式进行恢复。在标准取回模式下恢复时间为12 - 24小时；在批量取回模式下恢复时间为24 - 48小时。

不同模式的数据取回费用不同，费用详情请参见 [数据取回费用](https://cloud.tencent.com/document/product/436/53862)。

同时控制台、API、SDK、COSCMD 工具都支持归档存储恢复与下载。

## 直传归档限制说明

下载归档类型（例如归档存储、深度归档存储等）的对象，需要先进行恢复，然后再进行下载。

复制归档类型（例如归档存储、深度归档存储等）的对象，需要先进行恢复，然后再进行复制。

归档类型（例如归档存储、深度归档存储等）的对象不支持跨地域复制。

归档类型（例如归档存储、深度归档存储等）的对象不支持转换为较活跃的存储类型，例如标准存储、低频存储。
