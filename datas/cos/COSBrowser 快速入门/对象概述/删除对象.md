# 删除对象

最近更新时间：2026-03-13 15:24:42


## 简介

腾讯云对象存储（Cloud Object Storage，COS）支持对上传到存储桶中的单个或多个对象进行删除。您可以通过控制台、 API、SDK 等多种方式批量删除对象。默认情况下，当删除任务都成功完成时，返回的内容通常为空。若有发生错误，则会返回错误信息。

**说明：**

单次请求最多可删除1000个对象，若需要删除更多对象，请将列表拆分后分别发送请求。

如果您选择删除“文件夹”，则会同时删除“文件夹”下所有对象，在未开启版本控制的情况下，删除数据将不可恢复和访问。

如果您的存储桶已开启版本控制（包括启用和暂停状态），不指定版本 ID 执行删除操作并不会真实将对象删除，而是会给当前版本对象打上删除标记，同时您的存储量不会减少。如果您指定版本 ID（例如版本 ID 为10001）并执行删除操作，将会真实删除版本 ID 为10001的对象，该数据将不可恢复和访问，更多介绍请参见 [版本控制概述](https://cloud.tencent.com/document/product/436/19883)。

如果需要删除大量数据或者嵌套文件夹，您需要耗费较长时间才能完成删除，建议该类场景 [设置生命周期](https://cloud.tencent.com/document/product/436/14605) 进行删除。

## 适用场景

腾讯云对象存储（Cloud Object Storage，COS）支持直接删除一个或多个对象，当仅需要删除一个对象时，您只需要提供对象键，就可以调用一个 API 请求来删除它。

## 使用方法

### 使用对象存储控制台

#### 在未开启版本控制的存储桶中删除对象

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。

2. 在左侧导航栏中，单击**存储桶列表**，进入存储桶列表页面。

3. 找到对象所在的存储桶，单击其存储桶名称，进入存储桶管理页面。

4. 在左侧导航栏中，选择**文件列表**，进入文件列表页面。

5. 选择想要删除的单个或多个对象，单击上方的**更多操作**>**删除**。

6. 在弹出的提示窗口中，单击**删除**即可删除对象。

**注意：**

在此场景下删除对象，该对象将不可恢复和访问，请谨慎操作。

#### 在开启/暂停版本控制的存储桶中删除对象

**说明：**

如果存储桶曾经使用过版本控制功能，那么在删除对象时需要指定版本 ID 才能真实删除对象。如果不指定版本 ID 删除对象，则不会真实删除对象，而是给当前版本的对象添加一个删除标记，更多介绍请参见 [版本控制概述](https://cloud.tencent.com/document/product/436/19883)。

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。

2. 在左侧导航栏中，单击**存储桶列表**，进入存储桶列表页面。

3. 找到对象所在的存储桶，单击其存储桶名称，进入存储桶管理页面。

4. 在左侧导航栏中，选择**文件列表**，进入文件列表页面。

5. 在上方打开“列出历史版本”选项，然后勾选需要删除的单个或多个对象版本，单击上方的**更多操作**>**删除**。

6. 在弹出的提示窗口中，单击**删除**即可真实删除对象。

**注意：**

在此场景下删除对象，该对象将不可恢复和访问，请谨慎操作。

### 使用 REST API/SDK

您可以直接使用 REST API 发起删除单个或多个对象请求，请参见 [DELETE Object](https://cloud.tencent.com/document/product/436/7743) 和 [DELETE Multiple Objects](https://cloud.tencent.com/document/product/436/8289) API 文档。

您可以直接调用 SDK 的删除单个对象方法，详情请参见下列各语言 SDK 文档：

[Android](https://cloud.tencent.com/document/product/436/46418)、[C](https://cloud.tencent.com/document/product/436/65659)、[C++](https://cloud.tencent.com/document/product/436/35161)、[.NET(C#)](https://cloud.tencent.com/document/product/436/47233)、[Flutter](https://cloud.tencent.com/document/product/436/86290)、[Go](https://cloud.tencent.com/document/product/436/65648)、[iOS](https://cloud.tencent.com/document/product/436/46384)、[Java](https://cloud.tencent.com/document/product/436/65939)、[JavaScript](https://cloud.tencent.com/document/product/436/64963)、[Node.js](https://cloud.tencent.com/document/product/436/64983)、[PHP](https://cloud.tencent.com/document/product/436/64287)、[Python](https://cloud.tencent.com/document/product/436/65824)、[React Native](https://cloud.tencent.com/document/product/436/86702)、[小程序](https://cloud.tencent.com/document/product/436/64994)、[鸿蒙(Harmony)](https://cloud.tencent.com/document/product/436/112226)。
