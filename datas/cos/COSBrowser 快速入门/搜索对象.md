# 搜索对象

最近更新时间：2025-11-18 17:26:01


## 简介

您可以通过对象键或对象键中的某个参数来搜索已上传的对象、文件夹。

[对象键（ObjectKey）](https://cloud.tencent.com/document/product/436/13324#.E5.AF.B9.E8.B1.A1.E9.94.AE) 是对象在存储桶中的唯一标识，可以通俗的理解为文件路径。例如对象键为 doc/picture.jpg 则表示为图片文件 picture.jpg 存放在对象存储（Cloud Object Storage，COS）的 doc 路径（或文件夹）下。

列出对象键即按照指定的对象键来查找特定对象。此外，也可以按对象键前缀查找对象，即指定对象键前面的一部分（例如 doc）查找具有相同前缀 doc 的所有对象。

#### 适用场景

腾讯云 COS 支持按照前缀顺序列出对象键，您也可以在对象键中使用 `/` 字符来实现类似传统文件系统的层级结构，COS 也支持按照分隔符来做层级结构的选择和浏览。

您可以列出单个存储桶中的所有对象键，根据前缀的 UTF-8二进制顺序列出，或选择指定前缀过滤对象键的列表。例如加入参数 `t` 将列出 `tencent` 的对象，而跳过以 `a` 或其他字符为前缀的对象。

加入 `/` 分隔符将根据此分隔符重新组织对象键，您可以结合前缀和分隔符来实现类似文件夹检索的功能。

腾讯云 COS 在单个存储桶中支持无限数量的对象，因此对象键列表可能非常大。为了管理方便，单个列出对象接口将最多返回1000个对象列表，同时会返回指示器来告知是否存在截断，若存在截断，则表示下一页还存在对象列表。您可以根据指示器和分隔符多次发起列出对象键请求，实现列出所有对象键，或查询您所需要的内容。

## 使用方法

### 使用对象存储控制台

对象存储控制台支持前缀搜索和模糊搜索。

前缀搜索：根据相同的对象前缀进行搜索，并展示带有相同对象前缀的对象、文件夹的搜索结果。

模糊搜索：根据自定义关键词进行搜索，并展示包含该关键词的对象、文件夹的搜索结果。

**说明：**

搜索对象时所输入的对象前缀需区分英文大小写。

除此之外，您也可以使用 COSBrowser 工具进行模糊搜索，详情请参见 [COSBrowser 简介](https://cloud.tencent.com/document/product/436/11366)。

#### 使用前缀搜索对象

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。

2. 在左侧导航栏中，单击**存储桶列表**，进入存储桶列表页面。

3. 找到对象所在的存储桶，单击其存储桶名称，进入存储桶管理页面。

4. 在左侧导航栏中，选择**文件列表**，进入文件列表页面。

5. 在页面上方的搜索框中，输入对象的名称前缀，单击

，即可显示出当前存储桶中带有**相同名称前缀**的对象或文件夹。例如输入`img/`，则展示带有`img/`的对象、文件夹的搜索结果。

#### 使用模糊关键词搜索对象

1. 登录 [对象存储控制台](https://console.cloud.tencent.com/cos5)。

2. 在左侧导航栏中，单击**存储桶列表**，进入存储桶列表页面。

3. 找到对象所在的存储桶，单击其存储桶名称，进入存储桶管理页面。

4. 在左侧导航栏中，选择**文件列表**，进入文件列表页面。

5. 在页面上方的搜索框中，输入搜索关键词，单击

### 使用 REST API/SDK

您可以直接使用 REST API 发起列出对象键请求，详情请参见 [GET Bucket（List Objects）](https://cloud.tencent.com/document/product/436/7734) API 文档。

您可以直接调用 SDK 列出对象列表来实现搜索对象，详情请参见下列各语言 SDK 文档：

[Android](https://cloud.tencent.com/document/product/436/46417)、[C](https://cloud.tencent.com/document/product/436/65658)、[C++](https://cloud.tencent.com/document/product/436/109473)、[.NET](https://cloud.tencent.com/document/product/436/47232)、[Flutter](https://cloud.tencent.com/document/product/436/86289)、[Go](https://cloud.tencent.com/document/product/436/65647)、[iOS](https://cloud.tencent.com/document/product/436/46383)、[Java](https://cloud.tencent.com/document/product/436/65938)、[JavaScript](https://cloud.tencent.com/document/product/436/64962)、[Node.js](https://cloud.tencent.com/document/product/436/64982)、[PHP](https://cloud.tencent.com/document/product/436/64286)、[Python](https://cloud.tencent.com/document/product/436/65823)、[React Native](https://cloud.tencent.com/document/product/436/86701)、[小程序](https://cloud.tencent.com/document/product/436/64993)、[鸿蒙(Harmony)](https://cloud.tencent.com/document/product/436/115203)。
