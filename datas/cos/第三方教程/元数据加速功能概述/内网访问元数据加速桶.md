# 内网访问元数据加速桶

最近更新时间：2025-12-19 10:40:42


## 概述

本文档详细介绍了如何通过终端节点服务实现专线访问腾讯云对象存储（COS）元数据加速桶。元数据加速功能是 COS 面向大数据业务推出的高性能文件系统功能，底层采用卓越的元数据管理功能，支持通过 HDFS 语义访问对象存储服务，可达到百GB级别带宽、十万级QPS以及毫秒级延迟。

## 前置条件

在开始配置前，请确保满足以下条件：

**网络环境**：已配置支持 VPC 访问的云支撑环境，由网络 VPC 团队负责。

**终端节点服务**：COS 侧与 COS 元数据加速侧已创建终端节点服务，由 COS 元数据加速团队负责。

**白名单授权**：您的账号 UIN 已加入终端节点服务白名单，由 COS 元数据加速团队负责。

**元数据加速桶**：已创建开启元数据加速功能的存储桶。

## 费用说明

使用终端节点服务，会产生额外的费用，由 VPC 产品收取，详细的计费说明与示例请参见 [计费概述](https://cloud.tencent.com/document/product/1451/57263)。

## 操作步骤

1. 登录 [私有网络控制台](https://console.cloud.tencent.com/vpc/vpce?rid=33) 。

2. 切换至您要访问的元数据加速桶所在的地域，单击**新建**，根据以下参数配置说明完成终端节点的创建。

### 创建 COS 元数据加速服务终端节点

1. 登录 [私有网络控制台](https://console.cloud.tencent.com/vpc/vpce?rid=33) 。

2. 切换至您要访问的元数据加速桶所在的地域，新建终端节点，配置说明可以参见 [创建 COS 终端节点](https://cloud.tencent.com/document/product/436/124860#cd567380-870e-4bb4-98a5-72f1cf86de98)。注意 COS 元数据加速服务使用不同的终端节点服务，已部署终端节点的区域及对应服务 ID 如下表所示：

区域 终端节点服务 ID
北京 vpcsvc-dabvvd8k

**说明：**

如果您的元数据加速桶所在的地域没有对应的终端节点服务，可以 [联系我们](https://cloud.tencent.com/document/product/436/37708) 添加。

3. 验证并创建。点击**验证**，验证通过后单击**确定**创建终端节点，系统将自动生成 VIP 地址，请记录此 VIP 用于后续配置。

### 域名解析配置

完成终端节点的创建后，接下来需要在您的本地环境配置域名解析。总共需要配置两个域名的解析：

1. **COS 元数据加速服务域名解析**

域名格式：*.chdfs.<region>.myqcloud.com。

目标地址：[创建 COS 元数据加速服务终端节点](https://cloud.tencent.com/document/product/436/124860#e599a159-6b85-43a0-92f7-93004c7bc6ae) 生成的 VIP 地址。

2. **普通 COS 对象存储服务域名解析**

域名格式：*.cos.<region>.myqcloud.com。

目标地址： [创建 COS 终端节点](https://cloud.tencent.com/document/product/436/124860#cd567380-870e-4bb4-98a5-72f1cf86de98) 生成的 VIP 地址。

**注意：**

本地 hosts 文件不支持泛域名解析。如果是配置 hosts 的方式，请将泛域名中的 “*” 换成具体的 bucket-appid，示例：

10.0.0.12 examplebucket-1250000000.chdfs.ap-beijing.myqcloud.com

10.0.0.13 examplebucket-1250000000.cos.ap-beijing.myqcloud.com

### 验证与测试

1. **基础连通性测试**

使用 telnet 命令验证终端节点 VIP 的端口连通性：

 telnet <VIP> 80 # 验证 HTTP 端口

 telnet <VIP> 443 # 验证 HTTPS 端口

2. **内网访问验证**

在您的计算节点上，使用 nslookup 命令解析 COS 域名与元数据加速域名，若返回终端节点的 VIP，则表明域名解析成功。

3. **功能测试**

可参见 [挂载元数据加速桶](https://cloud.tencent.com/document/product/436/115666) 的内容，从计算节点访问元数据加速桶，看功能是否正常。
