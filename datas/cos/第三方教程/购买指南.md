# 购买指南

最近更新时间：2025-12-30 15:06:31


## 计费概述

COS 向量存储桶（COS Vector Bucket）采用后付费的计费模式，会按照实际使用的存储容量、写入数据量、查询量和请求次数进行计费，不同计费项的计费单位与结算周期有所不同。

## 计费项说明

向量存储桶的计费项、费用说明和计算公式如下所示：

计费项名称 计费项说明 计费公式 计费说明
存储容量费用 根据存储容量的大小进行计算 存储容量费用 = 存储容量单价 x 日存储容量 日存储容量 = 当日“每5分钟存储容量”之和 / 288（采样点数）
向量写入费用 根据写入的数据量的大小进行计算 向量写入费用 = 向量写入量单价 x 向量写入量 向量写入量 = 成功写入的向量和元数据的数据量之和
检索量费用 根据检索的数据量的大小进行计算 检索量费用 = 检索量单价 x 检索数据量之和 检索数据量之和 = 发起检索操作时的索引数据量之和
请求数费用 根据请求次数进行计算 请求数费用 = 请求数单价 x 请求数之和 请求数之和 = 所有向量存储桶请求次数之和

## 产品定价

计费项 计费周期 计费模式 计费单位
存储容量费用 日 后付费 元/GB/日
向量写入费用 日 后付费 元/GB
检索量费用 日 后付费 元/TB
