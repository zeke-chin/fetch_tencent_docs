# 简介

最近更新时间：2026-05-07 15:19:11


## 概述

COS Vectors Embedding CLI 是腾讯云对象存储（Cloud Object Storage, COS）向量存储桶的官方命令行工具。通过 COS Vectors Embedding CLI 工具，您可以通过简单的命令行指令将文本内容向量化并写入 COS 向量索引，以及对已存储的向量数据执行相似性检索。该工具封装了 “读取数据 > 调用 Embedding 模型 > 写入/检索向量” 的完整流程，只需一条命令即可完成操作。

COS Vectors Embedding CLI 使用 Python 编写，安装后您可以通过 `cos-vectors-embed [command] --help` 来查看 COS Vectors Embedding CLI 的使用方法

## 核心能力

**灵活的 Embedding 接入**：采用 OpenAI 兼容的 `/v1/embeddings` 标准协议，可无缝对接 OpenAI、Azure OpenAI、vLLM、Ollama 等任意兼容 API 服务，不绑定特定厂商。

**多源输入**：支持直接输入文本字符串、读取本地文件、读取 COS 对象，满足不同场景需求。

**批量处理**：通过本地 glob 通配符或 COS 前缀通配符进行批量文件处理，自动并行化以最大化吞吐量。

**深度定制**：灵活控制向量键命名、自定义元数据、推理参数等。

**向量检索**：支持文本相似度查询、元数据过滤、以及多种输出格式。
