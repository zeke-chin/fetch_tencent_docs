## 术语信息

使用 API 接口时会出现一些主要概念和术语，请见下表：

名称 描述
APPID 开发者访问 COS 服务时拥有的用户维度的唯一资源标识，用以标识资源，可在 [API 密钥管理](https://console.cloud.tencent.com/capi) 页面获取。
SecretId 开发者拥有的项目身份识别 ID，用于身份认证，可在 [API 密钥管理](https://console.cloud.tencent.com/capi) 页面获取。
SecretKey 开发者拥有的项目身份密钥，可在 [API 密钥管理](https://console.cloud.tencent.com/capi) 页面获取。
Bucket 向量存储桶，COS 中用于存储向量数据的容器。有关向量存储桶的进一步说明，请参见 [存储桶概述](https://cloud.tencent.com/document/product/436/126985) 文档。
BucketName-APPID 向量存储桶名称格式，用户在使用 API、SDK 时，需要按照此格式填写存储桶名称。例如 examplebucket-1250000000，含义为该向量存储桶 examplebucket 归属于 APPID 为1250000000的用户。
Index 桶内的索引对象，是存储向量的基本实体。
IndexName 索引名称，索引（Index）在存储桶（Bucket）中的唯一标识。有关索引与向量存储桶的进一步说明，请参见 [产品概述](https://cloud.tencent.com/document/product/436/126985) 文档。
Region 地域简称，当前可用地域请参见 [产品概述](https://cloud.tencent.com/document/product/436/126985) 文档。
Vector 存储在索引内部的向量数据。
