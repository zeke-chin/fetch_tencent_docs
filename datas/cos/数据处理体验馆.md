# 数据处理体验馆

最近更新时间：2025-02-28 20:22:13


数据处理体验馆，是用于展示和体验 COS 对象存储基于 [数据万象](https://cloud.tencent.com/document/product/460/6962) 丰富的数据处理能力的在线途径，有 Web 端和小程序端。

展示的能力范围包括：图片处理分析、内容审核、音视频处理分析、文档处理、智能音频、智能检索，可使用示例文件或自行上传文件体验。

## Web 端体验馆

您可直接在电脑端浏览器访问 [数据万象体验馆](https://cloud.tencent.com/act/pro/ciExhibition)，使用示例文件或自行上传文件，体验 COS 的数据处理功能。
