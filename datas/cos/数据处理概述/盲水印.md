# 盲水印

最近更新时间：2024-11-07 18:55:22


## 概述

盲水印功能基于腾讯云数据万象，是一种全新的水印模式。通过该功能，您可将水印图以不可见的形式添加到原图信息中，并不会对原图质量产生太大影响。在图片被盗取后，您可对疑似被盗取的资源进行盲水印提取，验证图片归属。

数据万象支持文字盲水印和图片盲水印，共分为以下几种类型：

水印类型 特性 适用场景
文字盲水印（type3）对画质影响较低，抗攻击性强，提取方便。终端信息添加
图片全盲水印（type2）对画质影响较低，提取水印需要水印图。批量添加，批量校验。
图片半盲水印（type1）抗攻击性强，提取水印需要原图。小图（640px x 640px 以下）使用。

**说明**

盲水印是付费服务，具体费用可查看 [图片处理费用](https://cloud.tencent.com/document/product/460/58117)，数据万象在账户首次产生该服务用量后，将发放一个用量为6000次，有效期为2个月的免费额度资源包，超出用量或资源包到期后将正常计费。

使用盲水印服务时，请先确认相关限制条件与地域，详情请见 [使用限制](https://cloud.tencent.com/document/product/460/36620)。

## 适用场景

**鉴权追责**：您可对图片资源增加盲水印，在发现恶意攻击方盗取您的资源后，可将疑似被盗图片取回并进行盲水印提取操作，若能够得到有效水印图，即可证明资源归属。

**上传查重**：为解决部分用户使用其他用户资源重复上传相同信息的问题（例如房产图、汽车图、商品图等），您可在用户上传图片资源前先进行盲水印提取，若提取到水印图信息则证明该图片来自之前已有资源，并进行相应操作（例如提醒用户请勿重复上传资源）。

**资源防泄露**：对于内部分享的图片资源，您可通过文字盲水印，在访问方请求图片时，将访问方的信息添加至图片中，当资源泄露后可通过流传出的资源图提取出盲水印，进而得到泄露方信息。

## 使用方法

### 使用对象存储控制台

您可以使用对象存储控制台开启盲水印，详情请参见 [设置盲水印](https://cloud.tencent.com/document/product/436/46780) 控制台指南文档。

### 使用 REST API

您可以使用 API 添加或提取盲水印，详情请参见 [盲水印](https://cloud.tencent.com/document/product/436/46782) API 文档。
