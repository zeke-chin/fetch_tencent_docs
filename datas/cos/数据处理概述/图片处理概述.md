# 图片处理概述

最近更新时间：2026-02-27 16:07:32


## 简介

COS 支持处理存储的图片，您可以通过在上传或下载图片时携带图片处理参数进行使用。支持的处理能力包含：裁剪、转格式、缩放、水印、压缩等基础处理和基于 AI 的识别分析的图像增强、图像标签、图像评分、图像修复、商品抠图等智能处理，满足多种业务场景下的图片处理需求。

**注意**

图片处理功能为收费项，由[数据万象](https://cloud.tencent.com/document/product/460/6962)收取，详细的计费说明请参见 [计费与定价](https://cloud.tencent.com/document/product/460/6970)。

暂不支持对多 AZ 存储桶中的图片进行处理。

[样式设置](https://cloud.tencent.com/document/product/460/6936)设置图片的样式，方便管理不同需求的图片
图片 AI 识别服务[图像修复](https://cloud.tencent.com/document/product/436/79043)将图片中的 LOGO、物体、水印等内容去除，并根据背景进行智能填充，有效对图片内特定区域进行修复重建。
[商品抠图](https://cloud.tencent.com/document/product/436/79733)智能识别图片中的主体部分，并将其余背景进行透明化。
[二维码识别](https://cloud.tencent.com/document/product/436/54070)识别图片中的二维码，并返回二维码的位置及其中包含的内容信息，并支持对识别出的二维码进行打码处理。
[图片标签](https://cloud.tencent.com/document/product/436/54067)智能识别图片中的场景、物品等信息，如动物（猫、狗、鸟类等）、美食（水果、蔬菜等），包含数十个分类及数千个标签。
[图片质量评估](https://cloud.tencent.com/document/product/436/64314)多方面评估图片的视觉质量，输出客观的清晰度评分和主观的美观度评分。
[人脸识别](https://cloud.tencent.com/document/product/436/54069)对给定的人脸图片，检测人脸位置、人脸面部属性、人脸质量信息，还支持人脸美颜、人像分割、年龄性别变换等特效能力。
[人脸核身](https://cloud.tencent.com/document/product/436/54073)提供身份证识别、人脸活体检测能力。
[汽车识别](https://cloud.tencent.com/document/product/436/64323)检测图片中的车辆，识别出车辆的品牌、颜色、位置、车牌等信息。
[文字识别](https://cloud.tencent.com/document/product/436/64324)将图片上的文字内容，智能识别为可编辑的文本。
以图搜图 通过存储桶建立图库，可在指定图库中快速搜索到相同或相似内容的图片集合。
其他图片服务[异常图片检测](https://cloud.tencent.com/document/product/436/75996)支持检测带有异常可疑信息的图片，如带有 TS 视频流。

## 使用方法

### 使用对象存储控制台

您可以使用对象存储控制台进行图片的基础处理设置，详情请参见 [基础图片处理控制台指南](https://cloud.tencent.com/document/product/436/42214)。

### 使用 REST API

您可以通过对象存储提供的 API 进行图片的基础处理或 AI 识别处理，详情请参见 [图片处理](https://cloud.tencent.com/document/product/436/54049) 及 [AI 内容识别](https://cloud.tencent.com/document/product/436/54065) API 文档。
