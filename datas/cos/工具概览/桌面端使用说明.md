## 登录软件

COSBrowser 桌面端支持多种登录方式：密钥登录、腾讯云账号登录、共享链接登录、授权码登录。支持同一账号多设备多点登录。

![Image 2](https://qcloudimg.tencent-cloud.cn/image/document/b8c32618fb2897c87e201faccef886f9.png)

密钥登录

腾讯云账号登录

共享链接登录

授权码登录

COSBrowser 支持通过永久密钥（即云 API 密钥）登录，配置项说明如下：

**SecretID、SecretKey**：云 API 密钥，该密钥可在访问管理控制台的 [API 密钥管理](https://console.cloud.tencent.com/cam/capi) 页面中创建并获取。

**存储桶/收藏路径**：若您当前使用的密钥仅允许访问指定资源范围且不允许访问存储桶列表，例如指定的存储桶或存储桶中某个路径，则填写后可快速进入对应的存储桶或文件路径。格式为：Bucket 或 Bucket/Object-prefix，例如当前使用的密钥仅被允许访问存储桶 examplebucket-1250000000 下的 doc 文件夹，则填写 examplebucket-1250000000/doc。操作指引请参见 [添加收藏路径](https://cloud.tencent.com/document/product/436/38103#path)。

**备注**：可对当前填入的永久密钥进行说明。例如操作人员、用途等。在**历史会话**中可用于区分不同的 SecretID。

**记住会话**：

若不勾选，则仅本次登录有效，退出登录则会清空填入的云 API 密钥（如果当前密钥已保存在历史会话中，则会从历史会话中移除）；

若勾选，在成功登录后将会记住填入的云 API 密钥相关信息，方便下次继续使用，您可在**历史会话**中管理已保存的密钥相关信息。

**注意：**

COSBrowser 不支持使用项目密钥进行登录。

为进一步提升账号与数据安全，COSBrowser Web 端已下线密钥登录方式，请使用腾讯云账号登录方式，或推荐使用 COSBrowser PC 客户端更安全、体验更好。

单击**腾讯云账号登录**，在弹窗中通过腾讯云账号登录 COSBrowser 桌面端。腾讯云账号支持的登录方式有微信、邮箱、QQ、微信公众号、企业微信、子用户登录。具体指引可参见 [账号相关文档](https://cloud.tencent.com/document/product/378)。

**注意：**

腾讯云账号登录方式会有会话超时限制，存在登录态失效问题，如果是上传大文件的场景建议使用密钥方式上传。

通过别人转发或分享的**共享链接**和**提取码**可以临时登录 COSBrowser 桌面端。功能介绍可参见 [分享文件/文件夹](https://cloud.tencent.com/document/product/436/38103#share)。

## 存储桶管理

**注意：**

此处功能介绍以 Windows 版本 v2.11.17为例，其他版本差异，请参见 [更新日志](https://github.com/tencentyun/cosbrowser/blob/master/changelog.md)。

### 创建/删除存储桶

功能 说明 如何操作
创建存储桶 可以通过客户端直接创建存储桶 1.在存储桶列表，单击左上角创建存储桶

2.正确填写存储桶名称，并选择地域、访问权限，也可根据用户需求设置存储桶标签

3.单击确定，即可完成创建
删除存储桶 删除存储桶前，请确认存储桶中数据已清空 1.在存储桶列表，单击对应存储桶右侧的更多按钮 -> 删除

2.确认存储桶中的数据已全部清空，单击确定进行删除

### 查看/配置存储桶

您可通过单击存储桶列表右侧的**详情**图标，可查看存储桶名称、地域、存储桶域名，可对存储桶访问权限、多 AZ 特性、智能分层、图片极智压缩、版本控制、全球加速等进行配置。

**注意：**

多 AZ 特性、智能分层目前仅支持部分地域，详情可参见 [多 AZ 特性概述](https://cloud.tencent.com/document/product/436/40548)、[智能分层存储简介](https://cloud.tencent.com/document/product/436/47802)。

### 搜索存储桶

可通过窗口右侧的搜索框，输入存储桶名称或者存储桶标签快速定位存储桶。

### 查看统计数据

您可通过单击存储桶列表右侧的更多按钮 >**统计**，查看存储桶的统计数据。存储桶数据包含存储用量和对象数量。

### 设置存储桶访问权限

COSBrowser 支持对存储桶的访问权限进行管理，方法如下：

存储桶权限管理：可通过单击存储桶列表右侧操作栏中的更多按钮 >**权限管理**，设置存储桶的公共权限和用户权限。

快速授权：可通过单击存储桶列表右侧操作栏中的**快速授权**，完成用户权限的授权。

**说明：**

有关 COS 的权限说明，可查看 [ACL 概述](https://cloud.tencent.com/document/product/436/30752)。

### 设置存储桶标签

您可通过单击存储桶列表右侧的更多按钮 >**标签管理**，查看、编辑或删除存储桶标签。

### 设置存储桶的上传/下载域名

您可通过单击存储桶列表右侧的更多按钮 >**传输管理**，对上传域名、下载域名进行指定，例如在已开启全球加速功能的存储桶中，可将上传、下载域名均设置为全球加速域名，设置后，您在上传或下载对象时将使用全球加速域名进行加速传输。

### 查看域名

您可通过单击存储桶列表右侧的更多按钮 >**查看域名**，可查看当前存储桶的域名配置情况，例如自定义 CDN 加速域名、自定义源站域名。

### 设置版本控制

您可通过单击存储桶列表右侧操作栏中的**详情**，在存储桶详情弹窗中，单击版本控制编辑图标，将当前状态修改为开启。开启版本控制后，您可查看同名文件的所有版本并对其进行管理，详情请参见 [查看历史版本或文件碎片](https://cloud.tencent.com/document/product/436/38103#versionid)。

### 设置全球加速

您可通过单击存储桶列表右侧操作栏中的**详情**，在存储桶详情弹窗中，单击全球加速编辑图标，将当前状态修改为开启，并将存储桶的上传/下载域名设置为全球加速域名。详情请参见 [设置存储桶的上传/下载域名](https://cloud.tencent.com/document/product/436/38103#domain)。

### 添加收藏路径

若您使用无访问存储桶列表权限的子账号（或密钥）进行登录，可以通过**添加收藏路径**的方式快速访问已被授权的存储桶资源，COSBrowser 提供了两种添加收藏路径的方式：

在软件登录界面，通过密钥登录方式，直接添加收藏路径，登录完成后，即可管理资源。

子账号登录后，在存储桶列表页左上角，单击**收藏的路径**>**添加路径**，并配置指定的路径和地域后进入存储桶管理资源。

**注意：**

如果通过 CAM 策略授权的路径中携带`/`，则在 COSBrowser 中添加收藏路径同样需加上`/` 。

### 生成授权码

通过生成授权码功能可实现对指定存储桶、存储桶下的资源和操作进行临时授权。相比分享文件夹功能更灵活，可以授予自定义操作权限和进入某个目录。通过生成临时使用的 SecretId、SecretKey、Token 和授权码，可实现临时登录客户端。

操作说明如下：

在工具界面右上方单击**工具箱**图标，在工具箱弹窗中选择**生成授权码**，然后选择想要生成授权码的存储桶和授权的资源范围，在 policy 权限设置中选择被授权的操作（例如读写权限），并设置授权码的有效时间（永久密钥登录最长可选择1.5天，腾讯云账号登录，最长可选择2小时），最后单击**确定**即可。

## 对象管理

### 上传文件/文件夹

上传功能 说明 如何操作
上传文件 COSBrowser 支持多种上传方式，支持单个或批量上传 上传文件的几种方式如下，在指定的存储桶或路径内：

1.单击上传，选择文件后，直接上传文件。

2.在文件列表空白处右键单击上传文件，进行上传。

3.通过鼠标将文件拖拽至文件列表窗口进行上传。
上传文件夹及其文件 若存储桶或路径内存在同名文件或文件夹，则默认覆盖 上传文件夹的几种方式如下，在指定的存储桶或路径内：

1.单击上传，选择文件夹，直接上传文件夹。

2.在文件列表空白处右键选择上传文件夹，进行上传。

3.通过鼠标将文件夹拖拽至文件列表窗口即可完成上传。
增量上传 增量上传指执行上传操作前，对上传文件与存储桶已有对象做比对， 若存在同名对象，则跳过该文件不执行上传操作 增量上传操作步骤如下，在指定的存储桶或路径内：

1.使用上传文件夹的方式，单击下一步。

2.存储方式选择跳过，单击上传后，即可完成增量上传。

**注意：**

若您需要大批量上传文件，建议电脑配置为4 核、运行内存16GB（最大支持一次性上传30万个文件）。

当上传的文件超过8MB时，将触发分块上传。若您使用的是子账号进行上传操作，那么请确保该账号下已拥有分块上传的相关权限，例如 [Initiate Multipart Upload](https://cloud.tencent.com/document/product/436/7746)、[Upload Part](https://cloud.tencent.com/document/product/436/7750)、[Complete Multipart Upload](https://cloud.tencent.com/document/product/436/7742)、[List Multipart Uploads](https://cloud.tencent.com/document/product/436/7736)（可选）权限。

### 下载文件/文件夹

下载功能 说明 如何操作
下载文件 COSBrowser 支持多种下载方式，支持单个或批量下载文件 下载文件的几种方式如下：

1.选中需要下载的文件，单击界面内的下载，即可下载该文件。

2.选中文件，右键单击下载。

3.通过鼠标将文件拖拽至本地的方式进行下载。
下载文件夹及其文件 若本地已存在同名文件或文件夹，则默认重命名 下载文件夹及其文件的几种方式如下：

1.选中需要下载的文件夹，通过单击界面内的下载，即可下载。

2.右键单击下载，直接下载该文件夹。

3.通过鼠标将文件夹拖拽至本地的方式进行下载。
增量下载 增量下载指执行下载操作前，将下载的对象与本地文件进行比对， 若存在同名对象，则跳过该对象不执行下载操作 增量下载操作步骤如下：

1.选中想要下载的文件/文件夹，然后单击鼠标右键。

2.在菜单中单击高级下载，在弹窗中选择跳过。

3.然后单击立即下载即可完成不重名文件/文件夹的增量下载。

**注意：**

 若您需要大批量下载文件，建议电脑配置为4 核、运行内存16GB（最大支持一次性下载30万个文件）。

### 删除文件/文件夹

**注意：**

文件/文件夹删除后，其对应的数据将无法再被访问，请谨慎操作。

选中想要删除的文件/文件夹，可通过单击界面上方**更多**中的**删除**或右键单击**删除**，即可完成文件/文件夹的删除，支持批量删除。

### 文件同步

用户可以通过文件同步功能，将指定本地文件夹中的文件同步上传到存储桶中。文件同步功能支持设置手动同步、自动同步和定时同步。

**注意：**

文件同步指在上传文件时，系统会自动识别本地目录与存储桶之间是否存在同样的文件，通过同步功能仅会上传存储桶中不存在的文件和变更过的文件。

目前同步功能，不会同步删除动作，即删除本地文件，不会同步删除 COS 存储桶中的文件。

目前仅支持将本地文件同步上传至存储桶，不支持逆向操作。

具体操作步骤如下：

1.单击界面右上方的**工具箱**>**文件同步**。

2.在弹窗中配置以下信息：

本地文件夹：指定将要同步上传的本地文件夹。

存储桶目录：上传到 COS 的存储桶目录。

文件后缀过滤：需要过滤的文件后缀。在同步时，将忽略带有该后缀的文件，如有多个，以英文`;`分隔。

同步类型：可选择单次同步、自动同步或者定时同步，然后单击**开始同步**，即可开启文件同步功能。

单次同步：即手动同步，在单击**开始同步**时，立即进行一次同步操作。

自动同步：当本地目录有文件变更或新文件时，系统会将对应的文件自动同步上传到指定的存储桶中。

定时同步：用户可以预先设置特定的时间点（例如每天或者每周某个时刻），以便系统在预定的时间点执行文件同步操作，确保文件保持同步。

![Image 7](https://qcloudimg.tencent-cloud.cn/image/document/6e9086763f5db24655b5a69957fef5dd.png)

3.单击**同步日志**，可查看文件的同步历史记录。

### 复制粘贴文件

在指定的存储桶或路径内，选中想要复制的文件/文件夹，可通过单击界面上方**更多**中的**复制**或右键单击**复制**，完成文件/文件夹的复制，复制成功后可在**其他存储桶或路径**中进行粘贴，支持批量复制粘贴。

**注意：**

对于已复制的文件或文件夹，若其粘贴的目标路径中包含同名文件，则默认覆盖。

### 文件重命名

选中想要重命名的文件，右键选择**重命名**或单击文件右侧**更多操作**中的**重命名**，输入文件名并保存，即可完成文件的重命名。

**说明：**

文件夹无法进行重命名操作。

### 新建文件夹

在指定的存储桶或路径内，单击界面内的**新建**>**新建文件夹**或在存储桶内空白处右键单击**新建文件夹**，输入文件夹名并确认，完成文件夹的创建。

**注意：**

文件夹名称不能超过255个字符。

允许使用数字、英文和可见字符的组合。

用`/`分隔路径，可快速创建子目录。

不允许以`/`开头和连续两个及以上`/`。

不允许文件夹名为空。

不允许直接以`..`作为文件夹名称。

文件夹无法进行重命名操作，请谨慎命名。

### 查看文件详情

可通过单击文件名或右键单击菜单中的**详情**来查看文件详情，文件详细信息包含文件名、文件大小、修改时间、访问权限、存储类型、ETag、Headers、指定域名、对象地址、创建临时链接。

### 生成文件链接

存在 COS 中的每个文件均可通过特定的链接来进行访问，若文件是私有读权限，则可通过请求临时签名的方式生成带有时效的临时访问链接。

生成文件链接有以下几种方式：

表格视图下，单击文件右侧的分享图标，可一键生成链接并复制。若文件为公有读权限，则链接不带签名永久有效。若文件为私有读权限，则链接带签名，2小时内有效。

选择文件后，右键单击**复制链接**，可一键生成链接并复制。若文件为公有读权限，则链接不带签名永久有效。若文件为私有读权限，则链接带签名，2小时内有效。

在文件详情中，单击**创建临时链接**，可以设置指定域名（例如开启了自定义 CDN 加速域名，则可设置）的临时链接、链接类型、有效时间。

**说明：**

如果您使用的是子账号，且需要切换使用其他域名（例如自定义 CDN 加速域名），操作前需确保主账号已为子账号授予`DescribeDomains`权限。

### 分享文件/文件夹

通过单击操作栏中的**分享**图标可分享单个文件。对文件夹单击右键菜单中的**分享**选项，可分享单个文件夹，并且支持设置分享的有效时间。

**说明：**

只支持单个文件夹的分享，不支持批量文件共享。

多人共享文件，很容易造成文件版本混乱。建议开启存储桶的版本控制功能，可以回溯至文件的历史版本。

![Image 10](https://qcloudimg.tencent-cloud.cn/image/document/a18d1584de8078e4e5c22249618f3286.png)

参数 说明
权限 您可以设置分享文件夹的访问权限。

只读：通过访问链接可以拉取文件夹列表及下载文件夹中的文件 。

读写：通过访问链接可以拉取文件夹列表、下载文件夹中的文件、上传文件至分享文件夹、新建文件夹。
有效时间 单位为分钟、小时或天。

使用密钥登录客户端：主账号有效期的取值范围为 1 分钟到 2 小时；子账号有效期的取值范围为 1 分钟到 30 天。

使用腾讯云账号登录客户端：支持设置的最长分享时间为 2 小时。默认值为当前账号允许的最长有效期。
提取码 6 位，默认系统自动生成，用户可自定义。支持输入数字、字母、符号。

**注意：**

在链接有效期内，收到分享链接及提取码的用户都可以通过该链接访问该文件夹。

### 文件预览

COSBrowser 支持预览媒体类文件，目前支持图片、视频、音频。可通过双击媒体格式文件或单击右键菜单中的**预览**或**播放**选项，即可打开文件预览界面。在文件预览或播放界面，您可以选择：

**下载**：将文件下载至本地，若本地存在同名文件，则默认覆盖。

**手机查看**：在预览界面会生成文件访问二维码，通过手机扫码可直接在手机上查看此文件。

**注意：**

## 软件设置

高级配置 说明 如何操作
通用配置 EndPoint/Service 域名：获取存储桶列表 API 时自定义请求域名。默认是 service.cos.myqcloud.com。

Bucket 域名模板：调用操作存储桶和对象的 API 时自定义请求域名。可以使用模板，如"{Bucket}.cos.{Region}.myqcloud.com"，即在调用 API 时会使用参数中传入的 Bucket 和 Region 进行替换。

自动切换备份域名：如果 Bucket 域名未配置或配置了 COS 默认域名，在请求出现网络错误时，会自动走备份域名重试 1 次。

使用 HTTPS：若要为您的存储桶域名使用 HTTPS，您需要在您的网站上安装 SSL 或 TLS 证书。 选择该选项会使请求更加安全。

 校验 HTTPS 证书：请求时是否校验 HTTPS 证书。1.选择高级设置 > 通用。

2.根据配置项说明，按需设置即可。
设置网络代理 COSBrowser 默认会使用系统配置的代理来尝试网络连接，请确保您的代理配置正常或请停用无法连接互联网的代理配置 1.选择高级设置 > 代理。
